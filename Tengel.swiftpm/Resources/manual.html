判定する（判定タブ）

レースとオッズを入れる

ひとことで

R・距離・馬場・頭数・単勝オッズ・3連単1位の6つを入れると、その場で判定が出るよ。

レース情報

  1. マザーデータ参考的中率に使うデータ。ふだんは1つ目（アプリに入っているデータ）のままでOK
  2. オッズ画像から読み取るスクショから全部入れてくれるよ（次の項目）
  3. 開催場・日付開催場は空でもOK（空なら、いま使っているマザーデータの開催場として判定）
  4. レース・距離レース番号はリストから選ぶ。距離はm
  5. 出走頭数・コースコースはダ（ダート）か芝
  6. 馬場状態良・稍重・重・不良。「重」だとA層になるよ

単勝・複勝オッズ

  • 馬番の横に単勝と複勝を入れる。複勝はなくても判定できるよ（大穴・超大穴の番号を並べる順番に使う）
  • 複勝が幅（1.2-1.5 など）のときは、下の数字（1.2）だけでOK（数字のキーボードでは「-」が打てないからね）
  • 取消・除外の馬は、単勝を空欄のまま。馬番が足りないときは＋馬番を1つ増やす
  • 単勝の一覧がないときは、「単勝1位オッズ」だけでも判定できるよ（そのときは馬番が出ない）

3連単（人気順）

  1. 1位オッズ・組番1位オッズは必ず入れる（層を決める「比」に使う）。組番はなくてもOKで、「.」で区切れる（3.1.5 → 3-1-5）
  2. 5位・10位オッズ記録用。なくても判定できるよ
  3. 入力をクリア／入力例を入れるクリアはR・距離・頭数・オッズを消す。入力例は架空のレースで動きを試せる（保存はできない）
注意「入力をクリア」しても、開催場・日付・コース・馬場は残るよ。前のレースで「重」にしていたら、次のレースで押し直してね（重だとA層になるから）。

入力中は、下に判定が出る

入力欄を見ている間は、下にこのバーが出るよ。押すと判定結果まで移動するよ。

ポイント足りない項目があると「判定不可（データ不足）」と出て、足りない項目を教えてくれるよ。

入れた開催場が、使っているマザーデータの開催場と違うと【参考判定】になるよ。開催場に合うマザーデータがあれば、切り替えるボタンが出るよ。

オッズ画像から読み取る

ひとことで

スクショを1〜3枚選ぶだけで、入力欄が埋まるよ。文字はこの端末の中で読むので、通信も追加の料金もいらないよ。

使い方

  1. オッズ画像から読み取るを押す
  2. 単勝の画面と、3連単の人気順の画面のスクショを1〜3枚選ぶ
  3. 10秒くらいで入力欄に入って「読み取った：…」と出る（電波はいらないよ）
  4. 「読めなかった：…」と出た項目は、前の値が残っているので必ず手で入れ直す
  5. オッズと頭数だけは、もとの画面と見比べて確かめてね
  1. 読み取りのボタン押すと写真を選ぶ画面になる（カメラで撮ってもOK）
  2. 読み取ったあと読み取った項目と、読めなかった項目が出るよ。読めなかった項目は手で入れてね

読み取るもの

開催場・日付・R・距離・コース・馬場・出走頭数・単勝・3連単の1位／5位／10位（組番も）。複勝は読まないよ（大穴の番号の並びに使うだけなので、なくても判定できるよ。入れたいときは手で）

うまく読み取るコツ

  • 単勝の表（馬番と単勝のオッズが並んだ画面）と、3連単の人気順（1位から順に組番とオッズが並んだ画面）を、それぞれ大きく写す
  • 画面を拡大して、1枚に表がおさまるように。文字が小さいときは2枚に分けてもOK（最大3枚）
  • 表の上に、開催場・R・距離・馬場・頭数が写っていると、そこも入るよ
  • 「オッズの表が見つからなかったよ」と出たら、表がはっきり写るように撮り直してね。いまの入力はそのまま残っているよ

ポイント（200P）

  • オッズが読めた読み込みに、1レース 200P 使うよ（レース情報しか読めなかったときは使わないよ）。ボタンの横に、いまのポイントが出るよ
  • 同じレースをもう一度読むときは 0P（オッズが変わったときなど）。同じ日付で、同じRか、同じレース名・距離・発走時刻なら同じレースとみなすよ
  • 単勝5連勝のレースを入れているときは、その予想の5レースで 200P だよ
  • ポイントが足りないときは読み取らないよ（いまの入力はそのまま）。「ポイントを買う」からポイントを足してね
  • 読み取れたレース名・発走時刻は「レース情報」の欄に入るよ（読めなかったら手で入れてもOK。同じレースの見分けに使うよ）
送らない文字の読み取りはこの端末の中（Appleの文字認識）で行うよ。画像も読んだ文字も、どこにも送らないし、料金もかからないよ。

買う馬を選ぶ

ひとことで

ゾーンの番号を押すと、その馬を「買う／買わない」に切り替えられるよ（買い目カスタム）。選んだ馬から買い目を作って予約するよ。「テンゲルにお任せ」でランダムにも選べるよ。

選び方

  1. 推奨ゾーンの番号（1着・2着・3着）を押す。うすくなった番号は「買わない馬」
  2. もう一度押すと、元に戻る
  3. 頭一つ残し：1着側・2着側はそれぞれ1頭は残す。3着は2本のゾーンを合わせて1頭残せばOK（片方のゾーンは全部外せるよ）
  • はじめは全部選んだ状態だよ
  • 🎲 テンゲルにお任せを押すと、推奨ゾーンの中の馬をランダムに選ぶよ（側ごとに1頭〜全部のくじ。押すたびに変わる。選んだあとで自分で直してもOK）。当たりやすさで選ぶわけではないよ
  • ゾーンの参考的中率のとなりに「選んだ馬で ○%」が出るよ。いま使っているマザーデータの同じ区分（層・帯）のレースで、1着・2着（3連単は3着まで）が「選んだ馬の人気」に入った割合だよ。全部選んでいるときはゾーンの値と同じ。レースが5走より少ないと「データ不足」
  • 選んだ馬は予約に残って、記録タブに「予約：人気→中穴（2着 7・1）」のように出るよ
  • 記録タブの「判定画面で開く」で、選んだ馬も戻るよ
  • 日付・開催場・レースを変えると、選び直しになるよ

結果と収支を記録する

ひとことで

判定の下の「買い目」で券種を選んで買い目を予約。買わないならこのレースを諦める。結果は記録タブの「予約レース」から入れるよ。

買い目のカード（判定の下）

  1. 券種を押す（はじめは馬単。3着のある区分は3連単も）。🔒の券種はPカスタムで解放すると選べるよ
  2. 使うゾーン：外したゾーンの馬は買い目に入れないよ（1つは使う）
  3. 買い目を確認で、券種ごとの組と点数が見られるよ（点数が出るのはここだけ）
  4. 買い目を予約→ 記録タブの「予約レース」に入る。発走時刻が入っていれば、発走の15分後にお知らせするよ
  5. 買わないレースはこのレースを諦める→「諦めたレース」に入る（お知らせなし）
  • 買い目は、選んだ馬から券種ごとに作るよ：単勝・複勝＝1着側の馬／馬単＝1着側→2着側／馬連・ワイド＝1着側と2着側の組（順番なし）／枠単・枠複＝その組を枠番に／3連単＝1着側→2着側→3着側（そのゾーンの3着で選んだ馬）／3連複＝その3頭。同じ組は1つにまとめるよ
  • 予約・諦めるにポイントは使わないよ（使うのは読み込みの200Pだけ）。予約・諦めたレースはミッションに数えるよ（同じレースは1回）
  • 同じレース（日付・開催場・R）の予約は1つ。読み直して馬を選び直したら選び直して予約し直すで上書き。結果を記録したレースは上書きしないよ
  • 予約を消すで予約とお知らせを消すよ。諦めたレースは、記録タブのやっぱり予約するで判定画面に戻って予約できるよ
  • 買い目を作るには馬番（単勝・複勝のオッズの一覧）が必要だよ

結果を入れる（記録タブ → 予約レース）

  1. 記録タブのいちばん上の予約レースから、そのレースを押して開く（お知らせを押しても開くよ）
  2. まず結果だけ：1着・2着・3着の馬番を入れる（同着は「6.2」のように2頭）。取消・除外の馬がいれば「取消・除外の馬番」に。レースが中止なら「中止」
  3. または📷 結果の画像から読むで、結果の画面のスクショ（1〜3枚）から着順と払戻を読んで入れるよ（読めなかったところは手で。この端末の中で読むよ）
  4. 結果を決める→ 券種ごとに的中／不的中／返還が決まって記録されるよ。当たりの大きさに合わせて的中ボタンの演出が出る（設定で的中エフェクトをオフにしていると、演出はとばして次へ）
  5. 演出をとじると、同じ行が金額の欄に変わるよ：券種ごとの購入額→払戻（購入額ははじめ1点100円。当たった券種の払戻は、画像に払戻があれば入っているよ）・マザーデータにも入れる・メモ
  6. 記録するで記録のできあがり。金額の入力は後からでもできるよ：あとで入れるで閉じても、月の一覧でその行を開けばいつでも入れられるよ

レースの読み込みにポイント（1レース 200P）を使うよ。はじめに 1,500P もらえて、足りなくなったら買えるよ。ポイントで券種やマザーデータの枠を増やしたり（Pカスタム）、記録の数でポイントがもらえたり（ミッション）するよ。

ポイントを買う

  • 設定タブのポイント→ポイントを買う。500P・1,000P・2,000P・4,000P のパック（買ったPに期限はないよ）
  • サブスクは 1か月ごとに自動で更新。月2,000P・月4,400P（うち400Pおまけ）・月9,200P（うち1,000Pおまけ）の3つ。届いたPは、届いた日から30日 使えるよ（次の月のPが届いても、期限までは残るよ）。無料トライアルはないよ
  • 買ったPから先に使うよ（サブスクのP → パックのP → もらったP）。ポイントはマイナスにならないよ（足りないときは使えない）
  • プランの変更・解約は、端末の「設定」→ Apple ID →「サブスクリプション」から。解約しても、届いたPは期限まで使えるよ
  • 詳しくで、ポイントの出入りの履歴と購入を復元（サブスクの状態をAppleと合わせる。もう足したPは2回足さないよ）

Pカスタム（解放）

  • 記録で選べる券種は、はじめは単勝・馬単・3連単。複勝・枠複・枠単・馬連・ワイド・3連複は、設定タブのPカスタムで 1つ 500P で解放すると選べるよ（🔒が取れるよ）
  • マザーデータの2つ目・3つ目の枠は 1つ 15,000P。解放すると、Excelや判定したレースで自分だけのマザーデータを作って、参考的中率を自分のデータで出せるよ
  • 解放したものはずっと使えるよ（アプリを消すと消えるよ）

200Pを使って読み込んで判定し、結果を記録したレースの数でポイントがもらえるよ。画面の上のミッション（か設定タブのミッション）で受け取るを押すと入るよ（押すまでは入らないよ。受け取れるときは上のミッションに赤い数字、設定タブに赤い印）。上のミッションには、つぎのミッションまでの数（いま／つぎ）も出るよ。

  • アプリを消すと、ポイント・解放したもの・記録はすべて消えて、もどせません。ポイントはこの端末の中だけに入っていて、ほかの端末には同期しないよ

ひとことで

区分ごとに、馬単の1着→2着と3連単の3着を変えられるよ。はじめは初期の買い目だよ。

  4. 1着・2着・3着ゾーンを押して選ぶ
  5. 的中数いま使っているマザーデータで、この買い目が当たった数

  • 「全部の区分を初期の買い目に戻す」で、いつでも元に戻せるよ

バックアップ

ひとことで

記録はアプリの中にも自動でバックアップされるよ。機種変更やアプリを消すときのために、ときどき「バックアップを保存」でファイルにも残してね。

  1. バックアップを保存記録（単勝5連勝も）・買い目の設定・マザーデータの名前・Excelで入れたマザーデータ・自分で入れたレースを1つのファイルに。出てきた画面で「"ファイル"に保存」などを選んでね
  2. バックアップから戻す保存したファイルを選ぶ
  • 戻すと、記録が足されるよ。同じレースは新しいほうが残って、いまある記録は消えないよ
  • ポイント・解放したものは、ファイルには入らないし、ファイルから戻らないよ（この端末の中だけ）

自動バックアップ

  • 記録や設定を保存するたびに、アプリの中のファイルにも自動で保存しているよ（設定タブの「自動バックアップ」に日時が出るよ）
  • もしアプリの中の記録が消えてしまっても、開いたときに「前の記録が見つかったよ。戻す？」と出るので、記録を戻すを押してね
  • アプリを削除すると、自動バックアップも消えるよ（記録・ポイント・解放したものはもどせないよ）。削除する前は、必ず「バックアップを保存」で記録をファイルに残してね
  • 自動バックアップにはポイントの台帳も入っているので、「記録を戻す」でポイントも戻るよ。「バックアップを保存」のファイルにはポイントは入らないよ

機種変更のとき

  1. 前の端末で「バックアップを保存」→「"ファイル"に保存」（iCloud Driveなど）
  2. 新しい端末にテンゲルを入れる
  3. 「バックアップから戻す」で、保存したファイルを選ぶ

ポイント・解放したものは端末ごとなので、新しい端末には移らないよ（はじめての 1,500P は、前にもらっていればもう一度はもらえないよ）。

アプリを更新するとき

新しい版はApp Storeから届くよ。設定タブの「アプリの更新」で、いまの版とApp Storeの版を確かめられるよ。アップデートしても、記録・買い目の設定・マザーデータ（自分で入れたレースも）は消えないよ。くわしくは「アップデート（新しい版・データ）」を見てね。

  1. いまの版この端末に入っている版
  2. App StoreApp Storeに出ている版

ポイント端末の設定で、Appの自動アップデートをオンにしておくと、自動で新しい版になるよ。更新しても、記録・買い目の設定・マザーデータ（自分で入れたレースも）は消えないよ。

困ったとき

ひとことで

たいていは、画面に出たメッセージのとおりにすれば直るよ。押すと直し方が出るよ。

「判定不可（データ不足）」と出る
足りない項目が出るので、そこを入れてね（R・距離・馬場・頭数・単勝オッズ・3連単1位）。
「オッズ入力○頭／出走頭数○頭」と出る
取消・除外の馬や入れ忘れがないか確かめてね。判定は出走頭数で行うよ。
「オッズの表が見つからなかった」と出る
単勝の表と3連単の人気順が、大きくはっきり写るように撮り直してね（画面を拡大して撮るのがコツ）。いまの入力はそのまま残っているよ。
読めなかった項目がある
その項目は前の値が残っているので、手で入れ直してね。画面を大きめに撮ると読みやすいよ。
読み取った数字がちがう
その欄だけ手で直してね。読み取りはこの端末の中で行っていて、通信も料金もかからないから、何度でも試せるよ。
Excelを入れようとしたら断られた
入るのは検証データの形（A〜P列）だけだよ。「マザーデータ」の項目を見てね。
「この端末ではExcelファイルを直接読めない」と出る
iOS・iPadOSを新しくするか、A〜P列をコピーして貼り付けてね。
参考的中率が出ない
使っているマザーデータに、集計できるレースがないよ。判定画面の上で、レースが入っているマザーデータ（1つ目など）に切り替えてね。
着順で「読み方がいくつかある」と出る
「.」で区切って入れてね（例 1.12.3）。
「結果待ち」のまま
着順（3連単なら3着まで）を入れて、馬単・3連単は買ったゾーンを選んでね。ほかの券種は回収額（外れは0）を入れてね。

新しい版にしたい

新しいデータを入れたい
設定 →「データの更新」の「新しいデータがあるか確認」→「新しいデータを入れる」。ネットにつながっているときに押してね。
レースがマザーデータに入らない
着順の1着・2着が入っているか、「マザーデータにも入れる」で入れ先が選ばれているか確かめてね。もう入っているレース（Excelで入れたものなど）は、はじめ「入れない」になっているよ。
マザーデータに入れまちがえた
設定 → マザーデータ →「編集」→「レースを見る・直す」で、そのレースを押して直すか消してね。
記録が消えた
アプリの中の自動バックアップに記録があれば、開いたときに「前の記録が見つかったよ。戻す？」と出るよ。出ないときは、設定 →「バックアップから戻す」で、保存したファイルを選んでね。
1つ目のマザーデータがおかしい
設定 → マザーデータの1つ目 →「アプリに入っているデータに戻す」。判定に使えない形になっていたら、アプリを開いたときに自動で戻るよ。

それでも直らないときは、設定 →「このアプリについて」のお問い合わせ先に、画面のスクショを添えて連絡してね。

ひとことで

アプリに出てくる言葉の意味だよ。ルールは「テンゲルシステムⅢ」のとおり。

ゾーン（単勝の人気順）

人気中穴大穴超大穴対象外 12345678910111213〜

数字は単勝の人気順（オッズの低い順）。13番人気より下は対象外で、判定にも番号にも出ないよ。

層の決まり方

上から順に見て、最初に当てはまった層になるよ。比＝3連単1位オッズ ÷ 単勝1位オッズ（小数第2位を四捨五入）。

  1. 馬場が「重」→ A
  2. 3連単1位が62.4倍以上→ C
  3. 単勝1位が2.5倍以上で、比が16以上→ C
  4. 比が12以上→ B
  5. どれでもない→ A

C層の帯

  1. 1〜3R→ 非該当（序盤R）
  2. 比10以上で、14頭以上→ 第2段階
  3. 比10以上で、9頭以上→ 第1段階
  4. どれでもない→ 非該当

A層とB層は、R番号・頭数に関係なく固定のゾーンだよ。

比
3連単1位オッズ ÷ 単勝1位オッズ。小数第2位を四捨五入して、小数第1位まで
層（姫ゲート層）
レースの荒れやすさの分け方。A（堅）・B（警戒）・C（穴）。決まり方は上の図
区分
層と帯を合わせたもの：A層（固定）／B層（固定）／C層・非該当／C層・第1段階／C層・第2段階
序盤R
C層の1〜3R。人気→人気・人気→中穴にして、3着は見送り
大穴フィルター
C層の4R以降で使う2段階のゲート。第1段階＝比10以上で9頭以上、第2段階＝比10以上で14頭以上
ゾーン
単勝の人気順のまとまり。人気（1〜3）・中穴（4〜6）・大穴（7〜9）・超大穴（10〜12）
記号A〜L
単勝オッズの低い順（同じなら番号の若い順）に、A＝1位からL＝12位まで
推奨ゾーン
区分ごとに決まった馬単のゾーン（第1〜第3）。矢印は1着→2着で、人気→大穴と大穴→人気は別の馬券
3着（2本）
3連単の3着に入れるゾーン2つ。1・2着に使った人気馬は除いて読む
暫定
まだデータが少なくて、あとで見直す予定のゾーン
参考的中率
その区分で、そのゾーンが実際に出た割合（マザーデータの実測）。かけ算ではない
穴絡み
1着か2着に、大穴か超大穴が入ったレース
レース判定
その区分の人気→人気率で、【薄】55%以上・【並】30〜55%・【厚】30%未満。表示だけで、ゾーンは変えない
超大穴帯注意
超大穴（10〜12番人気）がいて、3連単5位が40倍以上のとき。表示だけ
比区分
C層の比20以上／比20未満。記録用で、判定には使わない
旧本線
前の版のゾーン。本線と比べるための記録用で、買い目じゃない
参考判定
使っているマザーデータと開催場が違うレース。同じ仕組みで判定して、参考値はそのマザーデータの実測
マザーデータ
参考的中率と実測①〜⑦を計算する、もとのデータ（3つまで）。基盤データともいう
自分で入力
アプリの中で入れたマザーデータのレース（判定＋着順・手で入れた・ファイルから足した）。アプリに入っているデータが新しくなっても消えない
マザー入り
記録タブの印。そのレースがマザーデータにも入っているよ
集計対象
マザーデータの行を集計に入れるか（1＝入れる・0＝入れない）
自己参照の除外
マザーデータに入っているレースを判定するときは、そのレース自身を外して参考値を計算すること
期間
前半（7/20〜8/17）・後半（8/31〜10/3）・新規（10/4〜10/7）・最新（10/8〜）
