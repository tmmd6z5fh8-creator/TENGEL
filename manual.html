判定する（判定タブ）

レースとオッズを入れる

ひとことで

R・距離・馬場・頭数・単勝オッズ・3連単1位の6つを入れると、その場で判定が出るよ。

レース情報

  1. マザーデータ参考的中率に使うデータ。ふだんは「大井競馬」のままでOK
  2. オッズ画像から読み取るスクショから全部入れてくれるよ（次の項目）
  3. 開催場・日付開催場は「大井」のように入れる
  4. レース・距離レース番号はリストから選ぶ。距離はm
  5. 出走頭数・コースコースはダ（ダート）か芝
  6. 馬場状態良・稍重・重・不良。「重」だとA層になるよ

単勝・複勝オッズ

  • 馬番の横に単勝と複勝を入れる。複勝はなくても判定できるよ（大穴・超大穴の番号を並べる順番に使う）
  • 複勝が幅（1.2-1.5 など）のときは、下の数字（1.2）だけでOK（iPhoneの数字キーでは「-」が打てないからね）
  • 取消・除外の馬は、単勝を空欄のまま。馬番が足りないときは＋馬番を1つ増やす
  • 単勝の一覧がないときは、「単勝1位オッズ」だけでも判定できるよ（そのときは馬番が出ない）

3連単（人気順）

  1. 1位オッズ・組番1位オッズは必ず入れる（層を決める「比」に使う）。組番はなくてもOKで、「.」で区切れる（3.1.5 → 3-1-5）
  2. 5位・10位オッズ記録用。なくても判定できるよ
  3. 入力をクリア／入力例を入れるクリアはR・距離・頭数・オッズを消す。入力例は架空のレースで動きを試せる（保存はできない）
注意「入力をクリア」しても、開催場・日付・コース・馬場は残るよ。前のレースで「重」にしていたら、次のレースで押し直してね（重だとA層になるから）。

入力中は、下に判定が出る

入力欄を見ている間は、下にこのバーが出るよ。押すと判定結果まで移動するよ。

ポイント足りない項目があると「判定不可（データ不足）」と出て、足りない項目を教えてくれるよ。

使っているマザーデータと開催場が違うと【参考判定】になるよ（大井のデータなら、大井以外のレース）。開催場に合うマザーデータがあれば、切り替えるボタンが出るよ。

判定する（判定タブ）

オッズ画像から読み取る

ひとことで

スクショを1〜3枚選ぶだけで、入力欄が埋まるよ。使うにはAPIキーが1回だけ必要。

使い方

  1. オッズ画像から読み取るを押す
  2. 単勝・複勝の画面と、3連単の人気順の画面のスクショを1〜3枚選ぶ
  3. 20〜60秒待つと、入力欄に入って「読み取った：…」と出る
  4. 「読めなかった：…」と出た項目は、前の値が残っているので必ず手で入れ直す
  5. オッズと頭数だけは、もとの画面と見比べて確かめてね

はじめて押したとき

  1. 読み取りのボタン押すと写真を選ぶ画面になる
  2. キーがまだないときこの案内が出るよ。「「画像の読み取り」の設定を開く」からキーを入れてね

読み取るもの

開催場・日付・R・距離・コース・馬場・出走頭数・単勝・複勝・3連単の1位／5位／10位（組番も）

ポイント料金は1回 約1〜4円（節約モードなら1円未満）。画面を大きめに撮ると読みやすいよ。

スクショは読み取りのためにAnthropicへ直接送られるよ。記録やほかのデータは送らないよ。キーの作り方は「画像の読み取り（APIキー）」を見てね。

ひとことで

まず一番上の「層」と、第1・第2…の「推奨ゾーン」を見ればOK。下にいくほど細かい情報だよ。

画面の見方

  1. 層と区分左のバッジが層（A＝堅・B＝警戒・C＝穴）。右が区分（「A層（固定）」「C層・第2段階」など）

  5. そのゾーンの馬番押すと買う馬を選べる（「買う馬を選ぶ」）
  6. 参考的中率と理由その区分で、そのゾーンが実際に出た割合（マザーデータの実測）
  7. 3着（2本）3連単の3着に入れるゾーンと馬番。1・2着に使った人気馬は除いて読む
  1. 番号の一覧人気・中穴・大穴・超大穴の馬番。13番人気より下は対象外
  2. レース判定その区分の人気→人気率・穴絡み率と、3連単の参考値

  5. 全文コピー・保存判定の全文をコピー／判定と結果を保存

買う馬を選ぶ

ひとことで

ゾーンの番号を押すと、その馬を「買う／買わない」に切り替えられるよ。当たり外れは選んだ馬で決まるよ。

選び方

  1. 推奨ゾーンの番号（1着・2着・3着）を押す。うすくなった番号は「買わない馬」
  2. もう一度押すと、元に戻る
  3. それぞれの欄で1頭は残す（全部は外せないよ）
  • はじめは全部選んだ状態だよ
  • 馬単・3連単の当たり外れは、買ったゾーンの「選んだ馬」で決まるよ（「当たり外れの決まり方」）
  • 選んだ馬は記録に残って、記録タブに「買った：人気→中穴（2着 7・1）」のように出るよ
  • 記録タブの「判定画面で開く」で、選んだ馬も戻るよ
  • 日付・開催場・レースを変えると、選び直しになるよ

記録する

結果と収支を記録する

ひとことで

買った券種・金額・着順を入れて「判定と結果を保存」。当たり外れと収支は自動で出るよ。

画面の見方

  1. 結果的中・不的中・結果待ちと、購入→回収（収支）。自動で出るよ
  2. 買った券種いくつでも選べる。はじめは馬単だけ選ばれているよ
  3. 券種ごとの金額購入額→回収額（円）。外れは0。券種ごとの当たり外れも出る
  1. 買ったゾーン本当に買ったゾーンを押す（馬単・3連単を選んだときだけ出る）
  2. 着順左で馬番か人気を選んで（馬番は単勝の一覧を入れたときだけ）、右に1着.2着.3着を「.」で区切って入れる（2.5.1 → 2-5-1）
  3. マザーデータにも入れる入れ先を選んでおくと、着順を入れて保存したときに、このレースがマザーデータにも1行入るよ。払戻（100円あたり）はわかれば。くわしくは「レースのデータを入れる」
  4. その他ふつうは「自動判定」。買わなかったら「未購入」、取消・中止は「払い戻し」
  5. 判定と結果を保存判定と、この記録を一緒に保存

入れる順番

  1. 買った券種を押す（買っていない券種は押して外す）
  2. 券種ごとに購入額→回収額を入れる（外れは0）
  3. 買ったゾーンを押す
  4. 着順を入れる
  5. 「マザーデータにも入れる」の入れ先を確かめる（はじめから選んであるよ）
  6. 判定と結果を保存を押す
ポイントレース前でも保存できるよ。着順や回収額が空なら「結果待ち」で保存して、あとで足せばOK。
  • 同じ日・同じ開催場・同じRの記録は1つだけ。もう一度保存すると「上書き保存」になるよ
  • 「未購入」は収支に入らない。「払い戻し」は、回収額が空なら購入額と同じで計算するよ
  • メモには買い目などを自由に書けるよ
  • 消すときは記録を削除→ もう一度消す
マザーデータ購入額・回収額は自分の収支のためだけで、マザーデータには入らないよ。マザーデータに入るのは、「マザーデータにも入れる」を選んだときの、このレースのオッズと着順（と払戻）だけだよ。

記録する

当たり外れの決まり方

ひとことで

馬単・3連単は「買ったゾーン」と「選んだ馬」で、ほかの券種は回収額で決まるよ。どれか1つでも当たれば、そのレースは的中。

券種的中になるとき
馬単1着・2着が、買ったゾーンの選んだ馬
3連単馬単が的中して、3着もそのゾーンの3着（選んだ馬）
単勝・複勝・馬連・ワイド・3連複回収額が入っている（0なら不的中、空なら結果待ち）
レース全体どれか1つでも的中なら的中

例で見てみよう

A層のレースで、第2「人気→中穴」だけを馬単と3連単で買った。2着の6番人気（4番）は外した、とするよ。

結果 2番人気 → 5番人気 → 1番人気的中

人気→中穴なので、買ったゾーン第2に入って的中。3着の1番人気も3着「人気・中穴」に入るから、3連単も的中だよ。

結果 1番人気 → 3番人気 → 2番人気不的中

人気→人気なので第1には入ったけど、第1は買っていないゾーンだから不的中。

結果 2番人気 → 6番人気 → 1番人気不的中

ゾーンは第2で合っているけど、2着の6番人気は外した馬だから不的中。

B層・結果 1番人気 → 2番人気 → 3番人気不的中

人気→人気はB層の推奨ゾーン（中穴→人気・人気→大穴）にないので「推奨ゾーンの外」。

着順をまだ入れていない結果待ち

着順を入れると、自動で判定するよ。

ポイント馬単・3連単が的中して回収額が空だと、「回収額を入れてね💰」と教えてくれるよ。

前の記録（買ったゾーンを選ぶ機能ができる前のもの）は、推奨ゾーン全部で判定するよ。

WIN5の組み立て方

ひとことで

買う馬を自分で選ぶ

  • 番号を押すと、そのレースは自分で選んだ馬で固定。ほかのレースは、残りの予算で自動で出るよ
  • おまかせに戻すで、そのレースを自動に戻せる
  • 自分で選んだ馬だけで予算をこえると、赤で「馬を外すか予算を上げてね」と出るよ

推奨と、自動の選び方

  • 推奨は、テンゲルの馬単ゾーンの1着側：A層→人気、B層→中穴・人気、C層・第1／第2段階→人気・中穴・大穴
  • 自動では、推奨ゾーンの順（B層なら中穴→人気）に、ゾーンの中は単勝オッズの低い順に並べて、当たる見込みが一番上がるレースから1頭ずつ足していくよ。予算が少ないと、後ろの順の馬（B層なら人気馬）がうすくなる
  • ランダムは、推奨から1つずつ選ぶよ。ランダムでもう一回と「推奨以外のゾーンもまぜる」もあるよ
  • 当たる目安は、マザーデータの区分ごとの1着ゾーンの実測と単勝オッズから出す目安だよ

書き出す・ファイルから足す

入るのは検証データのA〜P列の形だけ。分析シート・分析表は姫に送ってね（「大井のデータを新しくする」）。
「このiPhoneではExcelファイルを直接読めない」と出る
iOSを新しくするか、A〜P列をコピーして貼り付けてね。
参考的中率が出ない
使っているマザーデータに、集計できるレースがないよ。判定画面の上で「大井競馬」に切り替えてね。
着順で「読み方がいくつかある」と出る
「.」で区切って入れてね（例 1.12.3）。
「結果待ち」のまま
着順（3連単なら3着まで）を入れて、馬単・3連単は買ったゾーンを選んでね。ほかの券種は回収額（外れは0）を入れてね。
記録に「購入額未入力」と出る
記録タブでそのレースを開いて、購入額を入れてね。
判定画面で保存できない
入力例は保存できないよ。上に「WIN5の○レース目を入力中」と出ているときは、WIN5タブでまとめて記録してね。
レースがマザーデータに入らない
着順の1着・2着が入っているか、「マザーデータにも入れる」で入れ先が選ばれているか確かめてね。もう入っているレース（Excelで入れたものなど）は、はじめ「入れない」になっているよ。
マザーデータに入れまちがえた
設定 → マザーデータ →「編集」→「レースを見る・直す」で、そのレースを押して直すか消してね。
新しい版が来ない
設定 →「新しい版があるか確認」を、電波がいいところで押してね。
記録が消えた
アイコンを消すと記録も消えるよ。設定 →「バックアップから戻す」で、保存したファイルを選んでね。
大井のデータがおかしい
設定 → マザーデータの1つ目 →「アプリに入っている大井データに戻す」。判定に使えない形になっていたら、アプリを開いたときに自動で戻るよ。

それでも直らないときは、画面のスクショを姫に送ってね。

用語集

ひとことで

アプリに出てくる言葉の意味だよ。ルールは「テンゲルシステムⅢ 第13改訂版」のとおり。

ゾーン（単勝の人気順）

人気中穴大穴超大穴対象外 12345678910111213〜

数字は単勝の人気順（オッズの低い順）。13番人気より下は対象外で、判定にも番号にも出ないよ。

層の決まり方

上から順に見て、最初に当てはまった層になるよ。比＝3連単1位オッズ ÷ 単勝1位オッズ（小数第2位を四捨五入）。

  1. 馬場が「重」→ A
  2. 3連単1位が62.4倍以上→ C
  3. 単勝1位が2.5倍以上で、比が16以上→ C
  4. 比が12以上→ B
  5. どれでもない→ A

C層の帯

  1. 1〜3R→ 非該当（序盤R）
  2. 比10以上で、14頭以上→ 第2段階
  3. 比10以上で、9頭以上→ 第1段階
  4. どれでもない→ 非該当

A層とB層は、R番号・頭数に関係なく固定のゾーンだよ。

ことば

比
3連単1位オッズ ÷ 単勝1位オッズ。小数第2位を四捨五入して、小数第1位まで
層（姫ゲート層）
レースの荒れやすさの分け方。A（堅）・B（警戒）・C（穴）。決まり方は上の図
区分
層と帯を合わせたもの：A層（固定）／B層（固定）／C層・非該当／C層・第1段階／C層・第2段階
序盤R
C層の1〜3R。人気→人気・人気→中穴にして、3着は見送り
大穴フィルター
C層の4R以降で使う2段階のゲート。第1段階＝比10以上で9頭以上、第2段階＝比10以上で14頭以上
ゾーン
単勝の人気順のまとまり。人気（1〜3）・中穴（4〜6）・大穴（7〜9）・超大穴（10〜12）
記号A〜L
単勝オッズの低い順（同じなら番号の若い順）に、A＝1位からL＝12位まで
推奨ゾーン
区分ごとに決まった馬単のゾーン（第1〜第3）。矢印は1着→2着で、人気→大穴と大穴→人気は別の馬券
3着（2本）
3連単の3着に入れるゾーン2つ。1・2着に使った人気馬は除いて読む
暫定
まだデータが少なくて、あとで見直す予定のゾーン
参考的中率
その区分で、そのゾーンが実際に出た割合（マザーデータの実測）。かけ算ではない
穴絡み
1着か2着に、大穴か超大穴が入ったレース
レース判定
その区分の人気→人気率で、【薄】55%以上・【並】30〜55%・【厚】30%未満。表示だけで、ゾーンは変えない
超大穴帯注意
超大穴（10〜12番人気）がいて、3連単5位が40倍以上のとき。表示だけ
比区分
C層の比20以上／比20未満。記録用で、判定には使わない
旧本線
第12改訂版のゾーン。本線（第13）と比べるための記録用で、買い目じゃない
参考判定
使っているマザーデータと開催場が違うレース。同じ仕組みで判定して、参考値はそのマザーデータの実測
マザーデータ
参考的中率と実測①〜⑦を計算する、もとのデータ（3つまで）。基盤データともいう
自分で入力
アプリの中で入れたマザーデータのレース（判定＋着順・手で入れた・ファイルから足した）。アプリに入っているデータが新しくなっても消えない
マザー入り
記録タブの印。そのレースがマザーデータにも入っているよ
集計対象
マザーデータの行を集計に入れるか（1＝入れる・0＝入れない）
自己参照の除外
マザーデータに入っているレースを判定するときは、そのレース自身を外して参考値を計算すること
期間
前半（7/20〜8/17）・後半（8/31〜10/3）・新規（10/4〜10/7）・第13新規（10/8〜）
カスタム買い目
設定の「買い目編集」で、第13改訂版の初期から変えた買い目
