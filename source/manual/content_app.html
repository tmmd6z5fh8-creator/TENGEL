ひとことで

オッズを入れるだけで、テンゲルⅢ（第13改訂版）の判定が全部出るアプリだよ。買った馬券の結果と収支も残せるよ。

画面の5つのタブ

{{shot:tabbar}}
タブできること
判定レースのオッズを入れて判定する。買った結果もここで記録する
WIN55レースの1着ゾーンと買う馬を、予算の中で出す
記録保存したレースの一覧。直す・開く・書き出す
実測・回収自分の収支と、マザーデータの実測①〜⑦
設定説明書・CM・買い目編集・マザーデータ・画像の読み取り・アプリの版・バックアップ・このアプリについて

タブは画面の下にあるよ。iPadを横にしたときなど、画面が広いときは上に出るよ。

おぼえておいてほしいこと

  • 判定はルールどおり機械的に出るよ。組番（○-○）と点数は出さない。WIN5だけは予算に合わせるので点数が出るよ。
  • 参考的中率は過去の実測だよ。これからの的中や利益を約束するものではないから、馬券を買うかどうかは自分で決めてね。馬券は20歳になってから。
  • 記録はこの端末の中だけに保存されるよ。外に送るのは、画像の読み取りでスクショをAnthropicに送るときだけ（CMを見るときは動画を読み込むよ）。
  • アプリを削除すると、記録も消えるよ。アプリの中にも自動でバックアップしているけど、ときどき「バックアップを保存」でファイルにも残してね。
{{i:spark}}ポイント大井のデータで見るとき、大井以外のレース（JRAやほかの地方競馬）は【参考判定】として出るよ。仕組みは同じで、参考値は大井の実測だよ。
{{i:book}}説明書この説明書は、アプリの画面の上にある説明書か、設定タブの説明書を開くで、いつでも見られるよ。電波がなくても読めるよ。
{{i:shield}}大切なこと免責・相談先・プライバシーポリシー・商標などは、設定タブのいちばん下のこのアプリについてにまとめてあるよ。
ひとことで

参考的中率と実測①〜⑦を計算する「もと」のデータ。3つまで持てて、切り替えられるよ。

{{shot:set_mother}}
  1. 1つ目：大井アプリに入っている290走（10/9まで）。「使用中」が、いま使っているデータ
  2. 2つ目・3つ目自分で入れるデータ。はじめは空（名前はJRA・船橋競馬）
  3. 編集名前・Excelファイル・元に戻すボタン

切り替える

  • 判定タブと実測タブの上の「マザーデータ」でも切り替えられるよ
  • 名前は16文字まで。名前に開催場の名前（JRAなら「JRA」か「中央」）を入れると、その開催場のレースはそのデータでふつうに判定されて、【参考判定】にならないよ
  • 記録と買い目の設定は、3つで共通だよ

Excelから入れる

  1. 編集を押してExcelファイルを選ぶ
  2. 入れる前に走数と期間が出るので、確かめる
  3. 「「○○」に入れる」を押す
  • 入れられるのは検証データの形（A〜P列）だけ（日付・R・馬場・距離・頭数・単勝1位・3連単1位・1着人気・2着人気・3着人気・3連単5位・3連単10位・馬単払戻・3連単払戻・備考・集計対象）
  • 形のちがうExcel（判定に使う列が入っていないものなど）は、理由を出して断るよ。いまのデータはそのまま
  • ファイルが選べないときは、A〜P列をコピーして貼り付けて「読み取る」

元に戻す

  • 「ひとつ前のデータに戻す」：入れ替える前に戻せる
  • 「このマザーデータを空にする」：2つ目・3つ目だけ
  • 「アプリに入っている大井データに戻す」：1つ目だけ
ひとことで

画像の読み取りには、AnthropicのAPIキーが1回だけ必要だよ。5分くらいで作れるよ。

キーの作り方

  1. Safariで platform.claude.com を開いてログイン（はじめてならアカウントを作る）
  2. Settings の Billing で、クレジットカードを登録してクレジット（残高）を入れる。5ドルあれば、標準でも200回以上読めるよ
  3. Settings の API keys →「Create key」→ 出てきた sk-ant-… をコピー（1回しか表示されないよ）
  4. テンゲルの設定 → 画像の読み取りの欄に貼って保存して試す
{{shot:set_ocr}}
  1. APIキーの欄・保存して試すsk-ant- ではじまる文字を貼って、「保存して試す」で使えるか確かめる
  2. モデル標準（正確・1回 約1〜4円）／節約（安い・1回 1円未満）
{{i:alert}}注意キーはこの端末の中だけに保存されるよ（バックアップにも入らない）。人には見せないでね。いらなくなったらキーを消す。APIの料金は、Anthropicに直接払うよ（このアプリの代金とは別）。
ひとことで

記録はアプリの中にも自動でバックアップされるよ。機種変更やアプリを消すときのために、ときどき「バックアップを保存」でファイルにも残してね。

{{shot:set_backup}}
  1. バックアップを保存記録（WIN5も）・買い目の設定・マザーデータの名前・Excelで入れたマザーデータを1つのファイルに。出てきた画面で「"ファイル"に保存」などを選んでね
  2. バックアップから戻す保存したファイルを選ぶ
  • 戻すと、記録が足されるよ。同じレースは新しいほうが残って、いまある記録は消えないよ
  • APIキーは入らないので、戻したあとに入れ直してね

自動バックアップ

  • 記録や設定を保存するたびに、アプリの中のファイルにも自動で保存しているよ（設定タブの「自動バックアップ」に日時が出るよ）
  • もしアプリの中の記録が消えてしまっても、開いたときに「前の記録が見つかったよ。戻す？」と出るので、記録を戻すを押してね
  • アプリを削除すると、自動バックアップも消えるよ。削除する前は、必ず「バックアップを保存」でファイルに残してね

機種変更のとき

  1. 前の端末で「バックアップを保存」→「"ファイル"に保存」（iCloud Driveなど）
  2. 新しい端末にテンゲルを入れる
  3. 「バックアップから戻す」で、保存したファイルを選ぶ
  4. APIキーを入れ直す

アプリの版

設定タブの「アプリの版」に、いまの版が出るよ。新しい版は、アプリのアップデートで届くよ。アップデートしても、記録・買い目の設定・マザーデータは消えないよ。

ひとことで

たいていは、画面に出たメッセージのとおりにすれば直るよ。押すと直し方が出るよ。

「判定不可（データ不足）」と出る
足りない項目が出るので、そこを入れてね（R・距離・馬場・頭数・単勝オッズ・3連単1位）。
「オッズ入力○頭／出走頭数○頭」と出る
取消・除外の馬や入れ忘れがないか確かめてね。判定は出走頭数で行うよ。
画像の読み取りで「APIキーが…」と出る
設定 → 画像の読み取りで、キーを入れるか確かめてね。
「クレジット（残高）が足りない」と出る
platform.claude.com の Billing でクレジットを入れてね。
「混み合ってる」「通信できなかった」と出る
少し待つか、電波がいいところでもう一度試してね。
読めなかった項目がある
その項目は前の値が残っているので、手で入れ直してね。画面を大きめに撮ると読みやすいよ。
Excelを入れようとしたら断られた
入るのは検証データの形（A〜P列）だけだよ。「マザーデータ」の項目を見てね。
「この端末ではExcelファイルを直接読めない」と出る
iOS・iPadOSを新しくするか、A〜P列をコピーして貼り付けてね。
参考的中率が出ない
使っているマザーデータに、集計できるレースがないよ。判定画面の上で「大井競馬」に切り替えてね。
着順で「読み方がいくつかある」と出る
「.」で区切って入れてね（例 1.12.3）。
「結果待ち」のまま
着順（3連単なら3着まで）を入れて、馬単・3連単は買ったゾーンを選んでね。ほかの券種は回収額（外れは0）を入れてね。
記録に「購入額未入力」と出る
記録タブでそのレースを開いて、購入額を入れてね。
判定画面で保存できない
入力例は保存できないよ。上に「WIN5の○レース目を入力中」と出ているときは、WIN5タブでまとめて記録してね。
新しい版にしたい
App Storeの「アップデート」から更新してね。記録は消えないよ。
記録が消えた
アプリの中の自動バックアップに記録があれば、開いたときに「前の記録が見つかったよ。戻す？」と出るよ。出ないときは、設定 →「バックアップから戻す」で、保存したファイルを選んでね。
大井のデータがおかしい
設定 → マザーデータの1つ目 →「アプリに入っている大井データに戻す」。判定に使えない形になっていたら、アプリを開いたときに自動で戻るよ。

それでも直らないときは、設定 →「このアプリについて」のお問い合わせ先に、画面のスクショを添えて連絡してね。
