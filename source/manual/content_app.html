ひとことで

オッズを入れるだけで、テンゲルⅢの判定が全部出るアプリだよ。買った馬券の結果と収支も残せるよ。

画面の5つのタブ

{{shot:tabbar}}
タブできること
判定レースのオッズを入れて判定する。買った結果もここで記録する
WIN55レースの1着ゾーンと買う馬を、予算の中で出す
記録保存したレースの一覧。直す・開く・書き出す

タブは画面の下にあるよ。iPadを横にしたときなど、画面が広いときは上に出るよ。

おぼえておいてほしいこと

  • 判定はルールどおり機械的に出るよ。組番（○-○）と点数は出さない。WIN5だけは予算に合わせるので点数が出るよ。
  • 参考的中率は過去の実測だよ。これからの的中や利益を約束するものではないから、馬券を買うかどうかは自分で決めてね。馬券は20歳になってから。
  • 記録はこの端末の中だけに保存されるよ。画像の読み取りも端末の中で行うので、スクショはどこにも送らないよ。新しい版・新しいデータがあるかは、App Storeと開発者のページに問い合わせて確かめるよ（記録や自分のことは送らないよ。CMを見るときは動画を読み込むよ）。
  • レースの読み込み（画像の読み取りから判定まで）に 1レース 200P 使うよ。はじめてアプリを入れたときに 1,500P もらえて、足りなくなったらポイントを買えるよ（くわしくは「ポイント・Pカスタム・ミッション」）。
  • アプリを削除すると、記録・ポイント・解放したものも消えて、もどせないよ。アプリの中にも自動でバックアップしているけど、ときどき「バックアップを保存」でファイルにも残してね（ポイントはファイルには入らないよ）。
{{i:spark}}ポイント入れた開催場が、使っているマザーデータの開催場とちがうときは【参考判定】として出るよ。仕組みは同じで、参考値はそのマザーデータの実測だよ。開催場が空なら、マザーデータの開催場のレースとして判定するよ。
{{i:book}}説明書この説明書は、アプリの画面の上にある説明書か、設定タブの説明書を開くで、いつでも見られるよ。電波がなくても読めるよ。
{{i:shield}}大切なこと免責・相談先・プライバシーポリシー・商標などは、設定タブのいちばん下のこのアプリについてにまとめてあるよ。
ひとことで

参考的中率と実測①〜⑦を計算する「もと」のデータ。3つまで持てて、切り替えられるよ。

{{shot:set_mother}}
  1. 1つ目アプリに入っているデータ（{{mother}}）。「使用中」が、いま使っているデータ
  2. 2つ目・3つ目自分で入れるデータ。はじめは空（名前は「マザーデータ2」「マザーデータ3」。自由に変えられるよ）
  3. 編集名前・レースのデータ（見る・直す・入れる・書き出す）・Excel／CSVファイル・元に戻すボタン
{{i:plusbox}}アプリの中で入れる判定したレースに着順を入れて保存するだけで、マザーデータに1行入るよ。1レースずつ見る・直す・消す・手で入れるもできるよ（「レースのデータを入れる」）。

切り替える

  • 判定タブと実測タブの上の「マザーデータ」でも切り替えられるよ
  • 名前は16文字まで。自分で入れたデータは、名前に開催場の名前を入れておくと（「○○競馬場」なら「○○」でOK）、その開催場のレースはそのデータでふつうに判定されて、【参考判定】にならないよ
  • 1つ目（アプリに入っているデータ）は、そのデータと同じ開催場のレースならふつうの判定、ちがう開催場のレースなら【参考判定】になるよ
  • 開催場が空のときは、使っているマザーデータの開催場のレースとして判定するよ
  • 記録と買い目の設定は、3つで共通だよ

Excel・CSVから入れる

  1. 編集を押してExcel・CSVファイルを選ぶ
  2. 入れる前に走数と期間、いまのデータとのちがい（新しい・変わる・なくなるレースの数）が出るので、確かめる
  3. 空のマザーデータなら「「○○」に入れる」。もう入っているときは足す（いまのレースは残す）か入れ替える（ファイルのとおり）を押す
  • 入れられるのは検証データの形（A〜P列）だけ（日付・R・馬場・距離・頭数・単勝1位・3連単1位・1着人気・2着人気・3着人気・3連単5位・3連単10位・馬単払戻・3連単払戻・備考・集計対象）。このアプリの「書き出す（CSV）」で作ったCSVも入るよ
  • 形のちがうExcel（判定に使う列が入っていないものなど）は、理由を出して断るよ。いまのデータはそのまま
  • ファイルが選べないときは、A〜P列をコピーして貼り付けて「読み取る」

元に戻す

  • 「ひとつ前のデータに戻す」：入れ替える前に戻せる
  • 「このマザーデータを空にする」：2つ目・3つ目だけ
  • 「アプリに入っているデータに戻す」：1つ目だけ（自分で入れたレースは残るよ）

1つ目（アプリに入っているデータ）は、アプリを更新しなくても「データの更新」で新しくできるよ（「アップデート（新しい版・データ）」）。

ひとことで

スクショを1〜3枚選ぶだけで、入力欄が埋まるよ。文字はこの端末の中で読むので、通信も追加の料金もいらないよ。

使い方

  1. オッズ画像から読み取るを押す
  2. 単勝・複勝の画面と、3連単の人気順の画面のスクショを1〜3枚選ぶ
  3. 10秒くらいで入力欄に入って「読み取った：…」と出る（電波はいらないよ）
  4. 「読めなかった：…」と出た項目は、前の値が残っているので必ず手で入れ直す
  5. オッズと頭数だけは、もとの画面と見比べて確かめてね
{{shot:ocr_done}}
  1. 読み取りのボタン押すと写真を選ぶ画面になる（カメラで撮ってもOK）
  2. 読み取ったあと読み取った項目と、読めなかった項目が出るよ。読めなかった項目は手で入れてね

読み取るもの

開催場・日付・R・距離・コース・馬場・出走頭数・単勝・複勝・3連単の1位／5位／10位（組番も）

うまく読み取るコツ

  • 単勝・複勝の表（馬番・単勝・複勝のオッズが並んだ画面）と、3連単の人気順（1位から順に組番とオッズが並んだ画面）を、それぞれ大きく写す
  • 画面を拡大して、1枚に表がおさまるように。文字が小さいときは2枚に分けてもOK（最大3枚）
  • 表の上に、開催場・R・距離・馬場・頭数が写っていると、そこも入るよ
  • 「オッズの表が見つからなかったよ」と出たら、表がはっきり写るように撮り直してね。いまの入力はそのまま残っているよ

ポイント（200P）

  • オッズが読めた読み込みに、1レース 200P 使うよ（レース情報しか読めなかったときは使わないよ）。ボタンの横に、いまのポイントが出るよ
  • 同じレースをもう一度読むときは 0P（オッズが変わったときなど）。同じ日付で、同じRか、同じレース名・距離・発走時刻なら同じレースとみなすよ
  • 5連の予想（5重勝）のレースを入れているときは、その予想の5レースで 200P だよ
  • ポイントが足りないときは読み取らないよ（いまの入力はそのまま）。「ポイントを買う」からポイントを足してね
  • 読み取れたレース名・発走時刻は「レース情報」の欄に入るよ（読めなかったら手で入れてもOK。同じレースの見分けに使うよ）
{{i:shield}}送らない文字の読み取りはこの端末の中（Appleの文字認識）で行うよ。画像も読んだ文字も、どこにも送らないし、料金もかからないよ。
ひとことで

記録はアプリの中にも自動でバックアップされるよ。機種変更やアプリを消すときのために、ときどき「バックアップを保存」でファイルにも残してね。

{{shot:set_backup}}
  1. バックアップを保存記録（WIN5も）・買い目の設定・マザーデータの名前・Excelで入れたマザーデータ・自分で入れたレースを1つのファイルに。出てきた画面で「"ファイル"に保存」などを選んでね
  2. バックアップから戻す保存したファイルを選ぶ
  • 戻すと、記録が足されるよ。同じレースは新しいほうが残って、いまある記録は消えないよ
  • ポイント・解放したものは、ファイルには入らないし、ファイルから戻らないよ（この端末の中だけ）

自動バックアップ

  • 記録や設定を保存するたびに、アプリの中のファイルにも自動で保存しているよ（設定タブの「自動バックアップ」に日時が出るよ）
  • もしアプリの中の記録が消えてしまっても、開いたときに「前の記録が見つかったよ。戻す？」と出るので、記録を戻すを押してね
  • アプリを削除すると、自動バックアップも消えるよ（記録・ポイント・解放したものはもどせないよ）。削除する前は、必ず「バックアップを保存」で記録をファイルに残してね
  • 自動バックアップにはポイントの台帳も入っているので、「記録を戻す」でポイントも戻るよ。「バックアップを保存」のファイルにはポイントは入らないよ

機種変更のとき

  1. 前の端末で「バックアップを保存」→「"ファイル"に保存」（iCloud Driveなど）
  2. 新しい端末にテンゲルを入れる
  3. 「バックアップから戻す」で、保存したファイルを選ぶ

ポイント・解放したものは端末ごとなので、新しい端末には移らないよ（はじめての 1,500P は、前にもらっていればもう一度はもらえないよ）。

アプリを更新するとき

新しい版はApp Storeから届くよ。設定タブの「アプリの更新」で、いまの版とApp Storeの版を確かめられるよ。アップデートしても、記録・買い目の設定・マザーデータ（自分で入れたレースも）は消えないよ。くわしくは「アップデート（新しい版・データ）」を見てね。

ひとことで

レースの読み込みにポイント（1レース 200P）を使うよ。はじめに 1,500P もらえて、足りなくなったら買えるよ。ポイントで券種やマザーデータの枠を増やしたり（Pカスタム）、記録の数でポイントがもらえたり（ミッション）するよ。

ポイントを使うこと・もらうこと

ことポイント
はじめてアプリを入れた1,500P もらえる（1回だけ。入れ直してももらえないよ）
レースの読み込み（画像の読み取りから判定まで）1レース 200P。同じレースの読み直しは 0P
5連の予想（5重勝）の読み込み5レースまとめて 200P
手で入れた判定・記録・買い目の編集・実測0P

マザーデータの枠の解放（2つ目・3つ目）1つ 15,000P

ポイントを買う

  • 設定タブのポイント→ポイントを買う。500P・1,000P・2,000P・4,000P のパック（買ったPに期限はないよ）
  • サブスクは 1か月ごとに自動で更新。月2,000P・月4,400P（うち400Pおまけ）・月9,200P（うち1,000Pおまけ）の3つ。届いたPは、届いた日から30日 使えるよ（次の月のPが届いても、期限までは残るよ）。無料トライアルはないよ
  • 買ったPから先に使うよ（サブスクのP → パックのP → もらったP）。ポイントはマイナスにならないよ（足りないときは使えない）
  • プランの変更・解約は、端末の「設定」→ Apple ID →「サブスクリプション」から。解約しても、届いたPは期限まで使えるよ
  • くわしくで、ポイントの出入りの履歴と購入を復元（サブスクの状態をAppleと合わせる。もう足したPは2回足さないよ）

Pカスタム（解放）

  • 記録で選べる券種は、はじめは単勝・馬単・3連単。複勝・枠複・枠単・馬連・ワイド・3連複は、設定タブのPカスタムで 1つ 500P で解放すると選べるよ（🔒が取れるよ）
  • マザーデータの2つ目・3つ目の枠は 1つ 15,000P。解放すると、Excelや判定したレースで自分だけのマザーデータを作って、参考的中率を自分のデータで出せるよ
  • 解放したものはずっと使えるよ（アプリを消すと消えるよ）

ミッション（記録でもらう）

200Pを使って読み込んで判定し、結果を記録したレースの数でポイントがもらえるよ。設定タブのミッションで受け取るを押すと入るよ（押すまでは入らないよ。受け取れるときは設定タブに赤い印）。

記録したレースもらえるP

40 / 60 / 85 / 1001,200 / 1,200 / 1,400 / 1,400
130 / 160 / 200 / 240 / 3001,600 / 1,600 / 1,800 / 1,800 / 2,000
そのあと 100レースごと2,000
  • 数えるのは、このアプリで 200P を使って読み込んで、結果を記録したレースだけ。同じレースは1回（読み直しても、記録を直しても1回）
  • Excel・CSV・貼り付けでまとめて入れたもの、手で入れたレース、バックアップから戻した記録、5連の予想の記録は数えないよ

大切なこと

  • アプリを消すと、ポイント・解放したもの・記録はすべて消えて、もどせません。ポイントはこの端末の中だけに入っていて、ほかの端末には同期しないよ
  • はじめての 1,500P は1回だけ。アプリを入れ直しても、同じApple IDのほかの端末でも、もう一度はもらえないよ
  • 買ったPの返金はAppleの決まりによるよ。返金があったときは、そのぶんのPを引くよ
ひとことで

アプリの新しい版はApp Storeから届くよ。1つ目のマザーデータ（アプリに入っているデータ）は、アプリの中の「データの更新」で新しくできるよ。

新しい版のお知らせ

{{shot:upd_bars}}
  • App Storeに新しい版が出ると、アプリを開いたときに上にお知らせが出るよ（新しいデータのお知らせも同じところに出るよ）
  • App Storeで更新を押すと、App Storeが開いて更新できるよ。×で閉じても、設定からいつでも確かめられるよ

データの更新

{{shot:upd_data}}
  1. いまのデータ1つ目のマザーデータの走数・期間と、そのうち自分で入れたレースの数
  2. 新しいデータがあるか確認新しいデータがあれば、走数と最後の日付が出るよ
  3. 新しいデータを入れる押すだけで新しいデータになるよ
  • 新しいデータがあるときは、アプリを開いたときに上にも「新しいデータがあるよ」と出るよ。入れるを押すだけ
  • 読むのはレースのデータだけ。自分で入れたレース・買ったレースの記録・買い目の設定はそのまま
  • 前のデータは、設定 → マザーデータの1つ目 →「ひとつ前のデータに戻す」で戻せるよ
  • 1つ目に自分のファイルのデータを入れているときは、入れると入れ替わるので「ほんとに入れ替える？」と聞くよ
  • 確かめるのも入れるのも、ネットにつながっているときだけだよ
ひとことで

たいていは、画面に出たメッセージのとおりにすれば直るよ。押すと直し方が出るよ。

「判定不可（データ不足）」と出る
足りない項目が出るので、そこを入れてね（R・距離・馬場・頭数・単勝オッズ・3連単1位）。
「オッズ入力○頭／出走頭数○頭」と出る
取消・除外の馬や入れ忘れがないか確かめてね。判定は出走頭数で行うよ。
「オッズの表が見つからなかった」と出る
単勝・複勝の表と3連単の人気順が、大きくはっきり写るように撮り直してね（画面を拡大して撮るのがコツ）。いまの入力はそのまま残っているよ。
読めなかった項目がある
その項目は前の値が残っているので、手で入れ直してね。画面を大きめに撮ると読みやすいよ。
読み取った数字がちがう
その欄だけ手で直してね。読み取りはこの端末の中で行っていて、通信も料金もかからないから、何度でも試せるよ。
Excelを入れようとしたら断られた
入るのは検証データの形（A〜P列）だけだよ。「マザーデータ」の項目を見てね。
「この端末ではExcelファイルを直接読めない」と出る
iOS・iPadOSを新しくするか、A〜P列をコピーして貼り付けてね。
参考的中率が出ない
使っているマザーデータに、集計できるレースがないよ。判定画面の上で、レースが入っているマザーデータ（1つ目など）に切り替えてね。
着順で「読み方がいくつかある」と出る
「.」で区切って入れてね（例 1.12.3）。
「結果待ち」のまま
着順（3連単なら3着まで）を入れて、馬単・3連単は買ったゾーンを選んでね。ほかの券種は回収額（外れは0）を入れてね。
記録に「購入額未入力」と出る
記録タブでそのレースを開いて、購入額を入れてね。
判定画面で保存できない
入力例は保存できないよ。上に「WIN5の○レース目を入力中」と出ているときは、WIN5タブでまとめて記録してね。
新しい版にしたい
設定 →「アプリの更新」の「新しい版があるか確認」→「App Storeで更新する」（App Storeの「アップデート」からでもOK）。記録は消えないよ。
新しいデータを入れたい
設定 →「データの更新」の「新しいデータがあるか確認」→「新しいデータを入れる」。ネットにつながっているときに押してね。
レースがマザーデータに入らない
着順の1着・2着が入っているか、「マザーデータにも入れる」で入れ先が選ばれているか確かめてね。もう入っているレース（Excelで入れたものなど）は、はじめ「入れない」になっているよ。
マザーデータに入れまちがえた
設定 → マザーデータ →「編集」→「レースを見る・直す」で、そのレースを押して直すか消してね。
記録が消えた
アプリの中の自動バックアップに記録があれば、開いたときに「前の記録が見つかったよ。戻す？」と出るよ。出ないときは、設定 →「バックアップから戻す」で、保存したファイルを選んでね。
1つ目のマザーデータがおかしい
設定 → マザーデータの1つ目 →「アプリに入っているデータに戻す」。判定に使えない形になっていたら、アプリを開いたときに自動で戻るよ。

それでも直らないときは、設定 →「このアプリについて」のお問い合わせ先に、画面のスクショを添えて連絡してね。
