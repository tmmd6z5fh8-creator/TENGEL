的中ボタン・デカ的中ボタン・フリーズ的中ボタン（デフォルト）

まさちゃんの指定：記録して 当たり → 的中ボタン、3連単が当たり → デカ的中ボタン、3連単の当たりに超大穴（10〜12番人気）の馬 → フリーズ的中ボタン。タップすると、壁紙の馬がボードを持って出てきて、当たった買い目を報告する。フリーズは、虹色にギラギラ光るめちゃくちゃデカいPUSH → タップで画面が止まって1秒グニャッと歪む（テレビの砂嵐が混ざる）→「プチュン」（1ピクセルの線がジリジリ → 光が横に走って消える）→ テンゲルのアイコンが虹色に光りながら画面いっぱいに上下に3秒 →「超大穴!!」→ 雷の中から馬がボード。となりの3つの画面は、タップで動く見本（どれもデフォルト＝全テーマ共通の動き）。

出るとき

  • 結果を記録したときだけ（あとで直したとき・まとめて入れた記録・外れ・中止では出ない）
  • 出るのは1つだけ。強い順に フリーズ（3連単が当たって、その3頭に超大穴＝10〜12番人気がいる。13番人気より下は入れない）＞ デカ（3連単が当たり）＞ 的中（それ以外の当たり）
  • 人気は、そのレースを判定したときの単勝オッズの順（判定の超大穴 J・K・L と同じ）。人気がわからないレースはフリーズにしない（デカ）※仮
  • お知らせ（発走15分後）から開いて記録したときも同じ

流れと時間（的中・デカ）

  • 的中：押す → 0.3秒 馬が下から → 0.95秒「的中！」→ 1.15秒〜 買い目 → 1.8秒 とじる
  • デカ：押す → 0.2秒 白く光る → 0.25秒 虹の光の筋と輪 → 0.85秒 光の中から馬 → 1.5秒「デカ的中!!」→ 1.75秒〜 買い目 → 2.5秒 とじる
  • PUSHは横長の長方形（角は丸い）。上下に0.9秒（デカは0.8秒・大きく・まわりに虹の輪）でくり返す

フリーズの流れと時間

  • PUSH：横340×縦170・角46px（デカの1.2倍）。虹色が流れる面・ラメ・白い光がサッと走る・白と紫のふち・まわりに虹の輪。上下に22px・0.85秒／1.3秒ごとにブルブルッ／画面のふちが虹色に光る
  • 歪み（0〜1秒）：押した瞬間の画面が止まって、細い帯（44本）に切れて波のように左右にずれる（だんだん強く・ちぎれる・色ずれ・走査線・縦にガクッ）。テレビの砂嵐が4回ザザッと強くなり、帯になって上から下へ流れ、最後は画面ぜんぶ砂嵐
  • プチュン（1秒）：砂嵐の画面が縦につぶれて、いちばん細い白い線（画面の点1つぶん）→ ジリジリ静電気（1.06〜1.5秒：線がチラチラ・細い火花・線のまわりに細かい砂嵐）→ 光が線の上を左から右へ走って、通ったところから消える（〜1.72秒）→ 真っ暗 → 2.12秒 まん中に光の星
  • 2.4〜5.4秒 テンゲルのアイコン（3秒）：ドーン（白い光・雷2本・ゆれ）→ アイコン（250px・角の丸い四角）が虹色に光りながら左右にブルブル、画面いっぱいに上下に3往復（虹色の残像3つ・上と下に当たるたびに白い輪とゆれ）・集中線・金のコイン・花火 → 上で止まる
  • 5.4秒〜「超」「大」「穴」「!!」が1文字ずつドン → 6秒 雷 → アイコンと文字が手前へ飛んで消える → 6.6秒 雷の中から馬がボード → 7.2秒「フリーズ的中!!!」→ 7.45秒〜 買い目 → 8.25秒 とじる

重ねる順（下から）

  • 的中・デカ：暗い幕 → 光 → 馬（うしろの絵）→ ボード（文字はHTML）→ 前足の先（前の絵）（ひづめがボードのふちにかかる）→ 紙ふぶき → とじる → （デカ）白い光
  • フリーズ：黒 → ゆれる層（夜空・光の筋・サーチライト・光・輪・雷・演出（集中線・コイン・花火・白い輪・アイコンの残像・アイコン・「超大穴!!」）・きらめき・コイン・馬とボード・紙ふぶき）→ 画面のふちの虹 → 歪み（押した瞬間の画面の絵を帯に切ったもの・走査線・ノイズ・砂嵐）→ プチュン（細かい砂嵐・線・火花・走る光）→ 星 → 白い光 → とじる

ボードに書くもの

  • R・当たった買い目（券種・馬番・金額・払戻）・払戻の合計。ユーザーが自分で入れた買い目だけ（判定の画面に点数・組番を出さない決まりはそのまま）
  • デカ・フリーズは3連単の行がいちばん上で虹色の枠（フリーズは光が走る）
  • フリーズ：見出し「フリーズ的中!!!」・その下に「超大穴 ⑪ 11番人気が3連単に！」の帯・3連単の行の超大穴の馬番に虹色の輪・ボードの枠は虹色（回さない）
  • 払戻が長いと次の行へ。帯のぶんボードが長いので、フリーズは6行まで（7つ以上は上から5行＋「ほか○点」※仮）

テーマ（壁紙）ごとに変えるところ

  • 馬の絵2枚（うしろ・前足の先）と、ボードの四角の位置
  • PUSHの色（--pushA・--pushB・--pushC・--rim・--rimD）・ボードの枠・面・文字（--bFrame・--bFace・--bInk・--hitRed）・光の色（--ray）
  • フリーズは全テーマ共通（変わるのは馬の絵とボードの面・文字だけ）。押したあとに回る虹（虹のぐるぐる）は使わない
  • シルバー帯・ゴールド帯・マスター帯は指示書9.1の指定どおり（あとで作る）

光と見やすさ

  • 強く光るのは1秒に3回まで（光の点めつで気分が悪くなる人がいるため）：1秒（プチュン）・2.4秒（ドーン）・6秒（雷）・6.6秒（雷と馬）。いちばん近いところでも1秒に2回。砂嵐は明るさがほぼ一定（灰色）
  • iPhoneの「視差効果を減らす」がオンなら：上下・ふるえ・回転・広がる光・紙ふぶき・きらめき・歪み・砂嵐・プチュン・アイコンの演出・ゆれ・雷・白い光を止める。フリーズは押すと1秒真っ暗 → 夜空の画面と馬・ボードをふわっと出す
  • 音は見本に入れていない

容量

  • 馬の絵は1テーマ約27KB（WebP 2枚）。フリーズで足す絵はテンゲルのアイコンだけ（App Storeのアイコンと同じ絵・WebP 750×750 約52KB）。虹・雷・コイン・星・花火・文字・砂嵐はCSSとSVG
  • 歪みに使う「押した瞬間の画面の絵」は、アプリでは押した瞬間に撮る（WKWebView の takeSnapshot）。見本では見本の画面の絵（WebP 約60KB）
  • 動きは全部CSS（動画なし）・新しいフォントなし（Dela Gothic One・BIZ UDPゴシック）。いまの馬は見本（牧場の栗毛）
