的中ボタン・デカ的中ボタン・フリーズ的中ボタン（デフォルト）・隠れど的中・ハズレ

まさちゃんの指定：記録して 当たり → 的中ボタン、3連単が当たり → デカ的中ボタン、3連単の当たりに超大穴（10〜12番人気）の馬 → フリーズ的中ボタン、デカ的中の2〜7回に1回（ランダム）→ 隠れど的中（デカのPUSHを押すと、そのまま、ど的中）、ハズレ → ボタンなしでボードだけ。タップすると壁紙のテーマのボードが出て、当たった買い目を報告する（馬がボードを持つのはやめた。的中もハズレも、ボードはテーマに沿った形）。フリーズは、まさちゃんの送ってくれたパチスロのフリーズの動画のように（台の絵や文字は使わない）：虹色にギラギラ光るめちゃくちゃデカいPUSH → タップで画面がバグる → テンゲルのアイコンのドアップ → 青白い横一本線に「プチュン」→ 真っ暗のまま1.5秒 → 虹色ネオンのカット（「どてき！！」「ど！ど！ど！ど！」）→「ど的中！！！！」（そろってから1.5秒）→ 炎の画面に、上に「ど的中」・炎の中からボード。文字はパチンコのロゴのような筆の字と虹色（まさちゃんの指定。写真の字の形は使わず、筆の動きから描いた）。視覚酔いしないように、画面全体が回る・迫る・ゆれる動きはしない。となりの5つの画面は、タップで動く見本（どれもデフォルト＝全テーマ共通の動き・ボードは牧場）。

結果のボード（壁紙のテーマごと）と、隠れど的中の決まり

  • 馬は出さない（まさちゃんの指定）。的中・デカ的中・ど的中・隠れど的中・ハズレ、どれも壁紙のテーマのボード。26テーマの見本は「結果のボード（26テーマ）」、作り方は boards.py
  • ボード＝そのテーマの判定画面をぎゅっと小さくした形：ふち＝背景のもよう（--bg と背景のルール）・見出し＝上の帯（--hd・--hdInk・--hdB・帯の飾り）・見出しの字＝ロゴと同じ（--dfont・--logo・--logoS）・買い目＝カード（--card・--cardB・--cardS）と行（--zBg・--zB）・券種＝タグ（--tagBg・--tagInk・--tagLine）・払戻＝--acc・合計＝--ink・すみの飾り（判定画面のカードと同じ所）。色は判定画面と同じ（コントラストを確かめた値）。馬番の枠の色は全テーマ同じ
  • デカ：まわりが光る・見出しは虹色（黒いふち）・3連単の行に虹色のふち。ど的中・隠れど的中：枠は虹色（回さない）・炎の光。ハズレ：見出しは上の帯の文字の色で静かに・払戻0円・光も紙ふぶきも音もなし
  • 隠れど的中：デカ的中が出るたびに数えて、2〜7回目（ランダム）の1回。出たら、次の回数をまた2〜7からランダムに決める。数は端末に保存（アプリを閉じても続く・記録やバックアップとは別）。本物のど的中（超大穴）は数えない ※仮
  • 見た目はデカ的中のPUSH（PUSHが出たときの音もデカ）→ タップでそのまま、ど的中の演出（押した瞬間の画面＝デカのPUSHの画面がバグる・音はど的中）→ 結果の見出し「隠れど的中！！！」・帯「隠れ　デカ的中が ど的中に化けた！」（超大穴の帯のかわり）

出るとき

  • 結果を記録したときだけ（あとで直したとき・まとめて入れた記録・中止では出ない）
  • 出るのは1つだけ。強い順に フリーズ（3連単が当たって、その3頭に超大穴＝10〜12番人気がいる。13番人気より下は入れない）＞ デカ（3連単が当たり。2〜7回に1回は隠れど的中）＞ 的中（それ以外の当たり）
  • ハズレ（当たりが1つもない）：PUSHは出さずに、ハズレのボードだけ
  • 人気は、そのレースを判定したときの単勝オッズの順（判定の超大穴 J・K・L と同じ）。人気がわからないレースはフリーズにしない（デカ）※仮
  • お知らせ（発走15分後）から開いて記録したときも同じ

流れと時間（的中・デカ・ハズレ）

  • 的中：押す → 0.3秒 ボードが下から → 0.95秒「的中！」→ 1.15秒〜 買い目 → 1.8秒 とじる
  • デカ（パチンコの当たりのように速く・勢いよく）：押す → 0.04秒 白く光る・爆発・虹の光の筋 → 0.1・0.25・0.4秒 虹の輪（キュウィン×3・だんだん大きく）→ 0.38秒 ボードがドンと落ちてくる（0.55秒 着地・光の破片）→ 0.7秒「デカ的中!!」がたたきつけるように → 0.9秒〜 買い目（0.08秒おき）→ 1.4秒 とじる
  • ハズレ：記録する → 暗い幕 → 0.1秒 ボードが静かに出る（0.4秒）→ 0.45秒〜 買い目（0.08秒おき）→ 0.85秒 とじる
  • PUSHは横長の長方形（角は丸い）。上下に0.9秒（デカは0.8秒・大きく・まわりに虹の輪）でくり返す

フリーズの流れと時間

  • PUSH：横340×縦170・角46px（デカの1.2倍）。虹色が流れる面・ラメ・白い光がサッと走る・白と紫のふち・まわりに虹の輪。上下に22px・0.85秒／1.3秒ごとにブルブルッ／画面のふちが虹色に光る
  • バグる（0〜1.4秒）：押した瞬間の画面に赤と水色の色ずれ（ずれ方が2回変わる）・1コマ（1/30秒）だけ横にズレる帯・ブロック・横の線（毎回ちがう場所）・走査線 → 0.5秒 一瞬もとに戻る → 0.86秒 テンゲルのアイコンのドアップ（虹色のネオンの線画・線はギザギザ。バグりながら少し引く）→ 1.2秒 横に流れる光の筋
  • プチュン（1.4秒〜）：画面が青く光って、まん中の白い光がふくらむ・稲妻がジリジリ → 1.64秒 画面が縦につぶれて青白い横一本線（まん中に光のフレア・線にまとわりつく静電気）→ 1.98秒 線が両はしから点に縮んで消える（光の粒が散る）→ 真っ暗のまま1.5秒（フリーズの間）
  • 虹色ネオンのカット（3.9〜8.28秒・5つ）：まさちゃんの指定の文字。パチンコのロゴのような筆の字と虹色（虹色の面・左上のふちが白く光る・上半分につや・こげ茶と金と黒のふち・金の立体・まわりに光。brush.py）。「どてき！！」「ど！」は1文字ずつ大きく、押した直後のPUSHのように乱れる（赤と水色のずれ・横にずれる帯・まわりに小さなブロック）。文字はたたきつけるように出て（0.16秒）、ずっとガクガクふるえる（左右上下と傾き・1秒に4回。筆の字は明るさの差が大きいので、光の点めつが多くならないように前より少なく）。パチンコの当たりのように速く・激しく：「！」「ど！」「ど的中」が出るたびに爆発（星形の光がはじける・衝撃の輪・光の破片が飛び散る）。場所・大きさ・向きはバラバラ：真っ暗から大爆発 → テンゲルのアイコンのネオンに「ど」「て」「き」「！」と大きな「！」（3.9秒〜）→ 星空に「どてき！！」（左上から右下へ階段・4.5秒〜）→ ネオンのギザギザに大きな「どてき！！」×2（画面からはみ出る・5.05秒〜）→ 星空に大きな「ど！」×4（5.65秒〜・0.17秒おき）→ ネオンのパチンコの当たりのような虹色（6.55秒〜）（黒に光る虹の光線・虹の輪・白く光るまん中と星・きらめき）に「ど的中」（光がサッと走る）「！！！！」（そろってから1.5秒）。この背景だけ動く：光の波が光線にそって外へ流れる（0.45秒ごと）・虹の輪が外へ広がって消える・まん中がふくらむ（回らない）。ほかのカットの背景は止まったまま
  • 8.28秒 結果：白く光る → 炎の画面で爆発、上に「ど的中」（筆の字・うしろで炎がゆらゆら・光がサッと走る・きらめき・SUPER LONGSHOT）・炎の中からボードがドンと出る → 8.58秒「ど的中！！！」（隠れど的中は「隠れど的中！！！」）→ 8.73秒〜 買い目（0.08秒おき）→ 9.22秒 とじる
  • 隠れど的中：デカのPUSH → タップで、ここに書いた流れと同じ（バグるのは、押した瞬間のデカのPUSHの画面）

重ねる順（下から）

  • 的中・デカ・ハズレ：暗い幕 → 光（ハズレはなし）→ テーマのボード（ふち＝背景のもよう → 上の帯と見出し → カードと買い目 → すみの飾り。文字はHTML）→ 紙ふぶき → とじる → （デカ）白い光
  • フリーズ・隠れど的中：黒 → 炎の画面（炎の色・光の筋・炎の粒・コイン・テーマのボード・「ど的中」・紙ふぶき）→ ネオンのカット（5つ・文字・白い光）→ プチュン（青い画面・白い光・線・フレア・稲妻・光の粒）→ バグる（押した瞬間の画面の絵・色ずれ・横ズレの帯・アイコンのドアップ・横に流れる光・走査線・ブロック・横の線）→ 白い光 → とじる

ボードに書くもの

  • 見出し（的中！・デカ的中!!・ど的中！！！・隠れど的中！！！・ハズレ。全角の「！」が3つ続くところは字の間をつめる）・R・買い目（券種・馬番・金額・払戻）・払戻の合計。ユーザーが自分で入れた買い目だけ（判定の画面に点数・組番を出さない決まりはそのまま）
  • 当たりは当たった買い目だけ。ハズレは入れた買い目を全部（払戻0円）・小見出しは「9R の買い目」
  • デカ・フリーズ・隠れど的中は3連単の行がいちばん上で虹色の枠（フリーズは光が走る）
  • フリーズ：上に「ど的中」（筆の字・炎）・見出しの下に「超大穴 ⑪ 11番人気が3連単に！」の帯・3連単の行の超大穴の馬番に虹色の輪。隠れど的中：帯は「隠れ　デカ的中が ど的中に化けた！」
  • 払戻が長いと、その行の払戻だけ次の行へ（右によせる）。帯のぶんボードが長いので、フリーズは6行まで（7つ以上は上から5行＋「ほか○点」※仮）

テーマ（壁紙）ごとに変えるところ

  • 結果のボード：判定画面と同じ変数と飾り（boards.py が themes20.py・判定画面から読む）。新しい絵はいらない
  • PUSHの色（--pushA・--pushB・--pushC・--rim・--rimD）・光の色（--ray）
  • フリーズは全テーマ共通（変わるのはボードだけ）。回る虹（虹のぐるぐる）は使わない（虹色は流れるだけ）
  • シルバー帯・ゴールド帯・マスター帯は指示書9.1の指定どおり（あとで作る）

光と見やすさ

  • 視覚酔いしないように：画面全体が回る・迫る（トンネル）・流れる・ゆれる動きはしない。背景は止めて、動くのは文字（ポンと出る・乱れる・ふるえる）・小さな光・炎の粒と、「ど的中！！！！」の背景の光の波と輪だけ（外へ広がる・回らない）。虹色が流れるのは4秒で1回りよりゆっくり
  • 強く光るのは画面のどの点でも1秒に3回まで（光の点めつで気分が悪くなる人がいるため。スマホは画面が目に近いので、画面の10%の広さでも数えた）。動画の明るさを1コマずつ・点ごとに測って確かめた。画面全体が白く光るのは デカの0.04秒（一瞬まっ白）・フリーズの 8.28秒（弱め）だけ。爆発の光は小さな範囲で1回ずつ。デカの虹の輪は同じ所が何回も光らないように大きさを変えた・虹の光の筋はゆっくり回す（30秒で1回り）・押したあとの暗い幕はPUSHの画面の暗さのまま始める（いったん明るくなってまた暗くなると、白い光の前にもう1回光ってしまう）。ハズレは光らない
  • iPhoneの「視差効果を減らす」がオンなら：バグる・プチュン・ネオンのカット・炎のゆらゆら・炎の粒・紙ふぶき・PUSHの動きを止める。押すと1秒真っ暗 → 炎の画面と「ど的中」（上）・ボードをふわっと出す。効果音は右の「効果音のメモ」（見本の画面もタップで鳴る）

容量

  • ボードに絵は使わない（テーマの色・もよう・飾りのSVGとCSSだけ。見出しの字はテーマの見出しのフォント）。フリーズで足す絵はテンゲルのアイコン（App Storeのアイコンと同じ絵・WebP 750×750 約52KB）と、アイコンから作ったネオンの線画のマスク2枚（芯 1024 約59KB・光 512 約40KB。neon_icon.py）。ほかの虹・文字・炎・ギザギザ・稲妻はCSSとSVG
  • バグるのに使う「押した瞬間の画面の絵」は、アプリでは押した瞬間に撮る（WKWebView の takeSnapshot）。見本では見本の画面の絵（フリーズのPUSH 約60KB・デカのPUSH 約36KB）
  • 動きは全部CSS（動画なし）・新しいフォントなし（テーマのフォント・Dela Gothic One・BIZ UDPゴシック）。ど的中の筆の字はフォントではなくSVGの形（brush.py で筆の動きから描いた6文字：ど・て・き・！・的・中。brush_glyphs.json 約12KB。金の立体とまわりの光は CSS の drop-shadow）
