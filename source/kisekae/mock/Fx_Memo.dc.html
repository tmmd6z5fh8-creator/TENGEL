的中ボタン・デカ的中ボタン・フリーズ的中ボタン（デフォルト）

まさちゃんの指定：記録して 当たり → 的中ボタン、3連単が当たり → デカ的中ボタン、3連単の当たりに超大穴（10〜12番人気）の馬 → フリーズ的中ボタン。タップすると、壁紙の馬がボードを持って出てきて、当たった買い目を報告する。フリーズは、まさちゃんの送ってくれたパチスロのフリーズの動画のように（台の絵や文字は使わない）：虹色にギラギラ光るめちゃくちゃデカいPUSH → タップで画面がバグる → テンゲルのアイコンのドアップ → 画面が青く光って青白い横一本線に「プチュン」（静電気がジリジリ → 点に縮んで消える）→ 真っ暗のまま1.5秒 → 虹色ネオンのカットに、押した直後のPUSHのように乱れて激しくふるえる大きなネオンの文字で「とんでも！」「とんでも！」「とんでも！とんでも！」「ど！ど！ど！ど！」（1文字ずつ・場所と向きはバラバラ・はみ出てもいい）→ ネオンのパチンコの当たりのような虹色に「ど的中！！！！」（そろってから1.5秒）→ 炎の画面に、上に小さく「ど的中」・炎の中から馬がボード。視覚酔いしないように、画面全体が回る・迫る・ゆれる動きはしない。となりの3つの画面は、タップで動く見本（どれもデフォルト＝全テーマ共通の動き）。

出るとき

  • 結果を記録したときだけ（あとで直したとき・まとめて入れた記録・外れ・中止では出ない）
  • 出るのは1つだけ。強い順に フリーズ（3連単が当たって、その3頭に超大穴＝10〜12番人気がいる。13番人気より下は入れない）＞ デカ（3連単が当たり）＞ 的中（それ以外の当たり）
  • 人気は、そのレースを判定したときの単勝オッズの順（判定の超大穴 J・K・L と同じ）。人気がわからないレースはフリーズにしない（デカ）※仮
  • お知らせ（発走15分後）から開いて記録したときも同じ

流れと時間（的中・デカ）

  • 的中：押す → 0.3秒 馬が下から → 0.95秒「的中！」→ 1.15秒〜 買い目 → 1.8秒 とじる
  • デカ：押す → 0.2秒 白く光る → 0.25秒 虹の光の筋と輪 → 0.85秒 光の中から馬 → 1.5秒「デカ的中!!」→ 1.75秒〜 買い目 → 2.5秒 とじる
  • PUSHは横長の長方形（角は丸い）。上下に0.9秒（デカは0.8秒・大きく・まわりに虹の輪）でくり返す

フリーズの流れと時間

  • PUSH：横340×縦170・角46px（デカの1.2倍）。虹色が流れる面・ラメ・白い光がサッと走る・白と紫のふち・まわりに虹の輪。上下に22px・0.85秒／1.3秒ごとにブルブルッ／画面のふちが虹色に光る
  • バグる（0〜1.4秒）：押した瞬間の画面に赤と水色の色ずれ（ずれ方が2回変わる）・1コマ（1/30秒）だけ横にズレる帯・ブロック・横の線（毎回ちがう場所）・走査線 → 0.5秒 一瞬もとに戻る → 0.86秒 テンゲルのアイコンのドアップ（虹色のネオンの線画・線はギザギザ。バグりながら少し引く）→ 1.2秒 横に流れる光の筋
  • プチュン（1.4秒〜）：画面が青く光って、まん中の白い光がふくらむ・稲妻がジリジリ → 1.64秒 画面が縦につぶれて青白い横一本線（まん中に光のフレア・線にまとわりつく静電気）→ 1.98秒 線が両はしから点に縮んで消える（光の粒が散る）→ 真っ暗のまま1.5秒（フリーズの間）
  • 虹色ネオンのカット（3.9〜9.2秒・5つ）：まさちゃんの指定の文字。「とんでも」「ど！」は1文字ずつ大きなネオン（色のこい塗り＋ちがう色のネオンのふち＋白い芯＋走査線）で、押した直後のPUSHのように乱れる（赤と水色のずれ・横にずれる帯・まわりに小さなブロック）。文字はずっと激しくガクガクふるえる（左右上下と傾き・1秒に約7回）。場所・大きさ・向きはバラバラ：真っ暗から → テンゲルのアイコンのネオンに「と」「ん」「で」「も」と大きな「！」→ 星空に「とんでも！」（左上から右下へ階段）→ ネオンのギザギザに大きな「とんでも！」×2（画面からはみ出る）→ 白く光る → 星空に大きな「ど！」×4 → ネオンのパチンコの当たりのような虹色（黒に光る虹の光線・虹の輪・白く光るまん中と星・きらめき）に「ど的中」「！！！！」（そろってから1.5秒）。この背景だけ動く：光の波が光線にそって外へ流れる（0.45秒ごと）・虹の輪が外へ広がって消える・まん中がふくらむ（回らない）。ほかのカットの背景は止まったまま
  • 9.2秒 結果：白く光る → 炎の画面に、上に小さく「ど的中」（炎がゆらゆら・光がサッと走る・きらめき・SUPER LONGSHOT）・炎の中から馬がボード → 9.8秒「フリーズ的中!!!」→ 10.05秒〜 買い目 → 10.85秒 とじる

重ねる順（下から）

  • 的中・デカ：暗い幕 → 光 → 馬（うしろの絵）→ ボード（文字はHTML）→ 前足の先（前の絵）（ひづめがボードのふちにかかる）→ 紙ふぶき → とじる → （デカ）白い光
  • フリーズ：黒 → 炎の画面（炎の色・光の筋・炎の粒・コイン・馬とボード・「ど的中」・紙ふぶき）→ ネオンのカット（5つ・文字・白い光）→ プチュン（青い画面・白い光・線・フレア・稲妻・光の粒）→ バグる（押した瞬間の画面の絵・色ずれ・横ズレの帯・アイコンのドアップ・横に流れる光・走査線・ブロック・横の線）→ 白い光 → とじる

ボードに書くもの

  • R・当たった買い目（券種・馬番・金額・払戻）・払戻の合計。ユーザーが自分で入れた買い目だけ（判定の画面に点数・組番を出さない決まりはそのまま）
  • デカ・フリーズは3連単の行がいちばん上で虹色の枠（フリーズは光が走る）
  • フリーズ：上に「ど的中」（炎）・見出し「フリーズ的中!!!」・その下に「超大穴 ⑪ 11番人気が3連単に！」の帯・3連単の行の超大穴の馬番に虹色の輪・ボードの枠は虹色（回さない）
  • 払戻が長いと次の行へ。帯のぶんボードが長いので、フリーズは6行まで（7つ以上は上から5行＋「ほか○点」※仮）

テーマ（壁紙）ごとに変えるところ

  • 馬の絵2枚（うしろ・前足の先）と、ボードの四角の位置
  • PUSHの色（--pushA・--pushB・--pushC・--rim・--rimD）・ボードの枠・面・文字（--bFrame・--bFace・--bInk・--hitRed）・光の色（--ray）
  • フリーズは全テーマ共通（変わるのは馬の絵とボードの面・文字だけ）。回る虹（虹のぐるぐる）は使わない（虹色は流れるだけ）
  • シルバー帯・ゴールド帯・マスター帯は指示書9.1の指定どおり（あとで作る）

光と見やすさ

  • 視覚酔いしないように：画面全体が回る・迫る（トンネル）・流れる・ゆれる動きはしない。背景は止めて、動くのは文字（ポンと出る・乱れる・ふるえる）・小さな光・炎の粒と、「ど的中！！！！」の背景の光の波と輪だけ（外へ広がる・回らない）。虹色が流れるのは4秒で1回りよりゆっくり
  • 強く光るのは画面のどの点でも1秒に3回まで（光の点めつで気分が悪くなる人がいるため。スマホは画面が目に近いので、画面の10%の広さでも数えた）。動画の明るさを1コマずつ・点ごとに測って確かめた。白く光るのは 6.1秒・9.2秒（どちらも弱め）
  • iPhoneの「視差効果を減らす」がオンなら：バグる・プチュン・ネオンのカット・炎のゆらゆら・炎の粒・紙ふぶき・PUSHの動きを止める。押すと1秒真っ暗 → 炎の画面と「ど的中」（上）・馬とボードをふわっと出す。効果音は右の「効果音のメモ」（見本の画面もタップで鳴る）

容量

  • 馬の絵は1テーマ約27KB（WebP 2枚）。フリーズで足す絵はテンゲルのアイコン（App Storeのアイコンと同じ絵・WebP 750×750 約52KB）と、アイコンから作ったネオンの線画のマスク2枚（芯 1024 約59KB・光 512 約40KB。neon_icon.py）。ほかの虹・文字・炎・ギザギザ・稲妻はCSSとSVG
  • バグるのに使う「押した瞬間の画面の絵」は、アプリでは押した瞬間に撮る（WKWebView の takeSnapshot）。見本では見本の画面の絵（WebP 約60KB）
  • 動きは全部CSS（動画なし）・新しいフォントなし（Dela Gothic One・BIZ UDPゴシック）。いまの馬は見本（牧場の栗毛）
