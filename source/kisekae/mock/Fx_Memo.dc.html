結果のボード（壁紙のテーマごと）と、隠れど的中の決まり

  • 馬は出さない（まさちゃんの指定）。的中・デカ的中・ど的中・隠れど的中・ハズレ、どれも壁紙のテーマのボード。26テーマの見本は「結果のボード（26テーマ）」、作り方は boards.py
  • ボード＝そのテーマの判定画面をぎゅっと小さくした形：ふち＝背景のもよう（--bg と背景のルール）・見出し＝上の帯（--hd・--hdInk・--hdB・帯の飾り）・見出しの字＝ロゴと同じ（--dfont・--logo・--logoS）・買い目＝カード（--card・--cardB・--cardS）と行（--zBg・--zB）・券種＝タグ（--tagBg・--tagInk・--tagLine）・払戻＝--acc・合計＝--ink・すみの飾り（判定画面のカードと同じ所）。色は判定画面と同じ（コントラストを確かめた値）。馬番の枠の色は全テーマ同じ

  • 見た目はデカ的中のPUSH（PUSHが出たときの音もデカ）→ タップでそのまま、ど的中の演出（押した瞬間にフリーズ・音はど的中）→ 結果の見出し「隠れど的中！！！」・帯「隠れ　デカ的中が ど的中に化けた！」（超大穴の帯のかわり）

出るとき

  • 結果を記録したときだけ（あとで直したとき・まとめて入れた記録・中止では出ない）
  • 出るのは1つだけ。強い順に フリーズ（3連単が当たって、その3頭に超大穴＝10〜12番人気がいる。13番人気より下は入れない）＞ デカ（3連単が当たり。2〜7回に1回は隠れど的中）＞ 的中（それ以外の当たり）
  • ハズレ（当たりが1つもない）：PUSHは出さずに、ハズレのボードだけ
  • 人気は、そのレースを判定したときの単勝オッズの順（判定の超大穴 J・K・L と同じ）。人気がわからないレースはフリーズにしない（デカ）※仮
  • お知らせ（発走15分後）から開いて記録したときも同じ

流れと時間（的中・デカ・ハズレ）

  • 的中：押す → 0.3秒 ボードが下から → 0.95秒「的中！」→ 1.15秒〜 買い目 → 1.8秒 とじる
  • デカ（パチンコの当たりのように速く・勢いよく）：押す → 0.04秒 白く光る・爆発・虹の光の筋 → 0.1・0.25・0.4秒 虹の輪（キュウィン×3・だんだん大きく）→ 0.38秒 ボードがドンと落ちてくる（0.55秒 着地・光の破片）→ 0.7秒「デカ的中!!」がたたきつけるように → 0.9秒〜 買い目（0.08秒おき）→ 1.4秒 とじる
  • ハズレ：記録する → 暗い幕 → 0.1秒 ボードが静かに出る（0.4秒）→ 0.45秒〜 買い目（0.08秒おき）→ 0.85秒 とじる
  • PUSHは横長の長方形（角は丸い）。上下に0.9秒（デカは0.8秒・大きく・まわりに虹の輪）でくり返す

フリーズの流れと時間

  • PUSH：横340×縦170・角46px（デカの1.2倍）。虹色が流れる面・ラメ・白い光がサッと走る・白と紫のふち・まわりに虹の輪。上下に22px・0.85秒／1.3秒ごとにブルブルッ／画面のふちが虹色に光る
  • 押した瞬間にフリーズ（0秒〜）（まさちゃんの指定：前のバグる画面はやめた。送ってくれたパチスロのフリーズの動画のような動き。台の絵は使わない）：1コマ＝1/30秒。白く光る（青いブロックが丸く集まる・縦に抜けた線）→ 0.07秒〜 明るい色の帯が横に流れる（コマごとに場所が変わる・下に緑と黄色）→ 0.2秒〜 まぶしい帯のある水色に赤い粒 → 0.3秒 青い画面にまぶしい横の帯・まん中の白い光がふくらむ・しぼむ・弓なりの電気・縦の点々 → 0.45秒 まわりが暗くなって青白い横一本線（まん中にフレア）・線にまとわりつく電気がバチバチ（いちばん細い線＝芯0.8px・枝0.5px。中点をずらして細かくギザギザ・枝分かれ・1コマごとに形が変わる）→ 0.62秒 線が両はしから点に縮んで消える（光の粒が下へ落ちながら散る）→ 真っ暗のまま1.5秒（フリーズの間）。走査線（1px）は 0.45秒まで
  • 虹色ネオンのカット（2.52〜6.9秒・5つ）：まさちゃんの指定の文字。パチンコのロゴのような筆の字と虹色（虹色の面・左上のふちが白く光る・上半分につや・こげ茶と金と黒のふち・金の立体・まわりに光。brush.py）。「どてき！！」「ど！」は1文字ずつ大きく、押した直後のPUSHのように乱れる（赤と水色のずれ・横にずれる帯・まわりに小さなブロック）。文字はたたきつけるように出て（0.16秒）、ずっとガクガクふるえる（左右上下と傾き・1秒に4回。筆の字は明るさの差が大きいので、光の点めつが多くならないように前より少なく）。パチンコの当たりのように速く・激しく：「！」「ど！」「ど的中」が出るたびに爆発（星形の光がはじける・衝撃の輪・光の破片が飛び散る）。場所・大きさ・向きはバラバラ：真っ暗から大爆発 → テンゲルのアイコンのネオンに「ど」「て」「き」「！」と大きな「！」（2.52秒〜）→ 星空に「どてき！！」（左上から右下へ階段・3.12秒〜）→ ネオンのギザギザに大きな「どてき！！」×2（画面からはみ出る・3.67秒〜）→ 星空に大きな「ど！」×4（4.27秒〜・0.17秒おき）→ ネオンのパチンコの当たりのような虹色（5.17秒〜）（黒に光る虹の光線・虹の輪・白く光るまん中と星・きらめき）に「ど的中」（光がサッと走る）「！！！！」（そろってから1.5秒）。この背景だけ動く：光の波が光線にそって外へ流れる（0.45秒ごと）・虹の輪が外へ広がって消える・まん中がふくらむ（回らない）。ほかのカットの背景は止まったまま
  • 6.9秒 結果：白く光る → 虹色の大当たりの画面（まさちゃんの指定。「ど的中」から虹色の光線と白い細い光線・まん中の白い光・虹の輪が外へ広がる（1.8秒ごと・2つ）・虹色のきらめきが上る・光線は止まったまま回さない）で爆発、上に「ど的中」（筆の字・うしろで虹色の炎がゆらゆら・光がサッと走る・きらめき・SUPER LONGSHOT）・まん中からボードがドンと出る → 7.2秒「ど的中！！！」（隠れど的中は「隠れど的中！！！」）→ 7.35秒〜 買い目（0.08秒おき）→ 7.84秒 とじる
  • 隠れど的中：デカのPUSH → タップで、ここに書いた流れと同じ（押した瞬間にフリーズ）

光と見やすさ

  • 視覚酔いしないように：画面全体が回る・迫る（トンネル）・流れる・ゆれる動きはしない。背景は止めて、動くのは文字（ポンと出る・乱れる・ふるえる）・小さな光・きらめきと、「ど的中！！！！」と結果の背景の光の波と輪だけ（外へ広がる・回らない）。虹色が流れるのは4秒で1回りよりゆっくり
  • 強く光るのは画面のどの点でも1秒に3回まで（光の点めつで気分が悪くなる人がいるため。スマホは画面が目に近いので、画面の10%の広さでも数えた）。動画の明るさを1コマずつ・点ごとに測って確かめた。画面全体が白く光るのは デカの0.04秒（一瞬まっ白）・フリーズの押した瞬間（白い画面。横に流れる帯は明るい色どうしで、切りかわっても点めつにならないようにした）・6.9秒（弱め）だけ。爆発の光は小さな範囲で1回ずつ。デカの虹の輪は同じ所が何回も光らないように大きさを変えた・虹の光の筋はゆっくり回す（30秒で1回り）・押したあとの暗い幕はPUSHの画面の暗さのまま始める（いったん明るくなってまた暗くなると、白い光の前にもう1回光ってしまう）。ハズレは光らない
  • iPhoneの「視差効果を減らす」がオンなら：フリーズ（プチュン）・ネオンのカット・虹の輪・炎のゆらゆら・きらめき・紙ふぶき・PUSHの動きを止める。押すと1秒真っ暗 → 虹色の画面と「ど的中」（上）・ボードをふわっと出す。効果音は右の「効果音のメモ」（見本の画面もタップで鳴る）
