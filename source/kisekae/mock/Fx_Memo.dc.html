的中ボタン・デカ的中ボタン・フリーズ的中ボタン（デフォルト）

まさちゃんの指定：記録して 当たり → 的中ボタン、3連単が当たり → デカ的中ボタン、3連単の当たりに超大穴（10〜12番人気）の馬 → フリーズ的中ボタン。タップすると、壁紙の馬がボードを持って出てきて、当たった買い目を報告する。フリーズは、まさちゃんの送ってくれたパチスロのフリーズの動画のように（台の絵や文字は使わない）：虹色にギラギラ光るめちゃくちゃデカいPUSH → タップで画面がバグる → テンゲルのアイコンのドアップ → 画面が青く光って青白い横一本線に「プチュン」（静電気がジリジリ → 点に縮んで消える）→ 真っ暗のまま2秒 → 虹色ネオンの超高速カット → 白い爆発 →「ど的中」が炎と光の中からドーン → 炎の中から馬がボード。となりの3つの画面は、タップで動く見本（どれもデフォルト＝全テーマ共通の動き）。

出るとき

  • 結果を記録したときだけ（あとで直したとき・まとめて入れた記録・外れ・中止では出ない）
  • 出るのは1つだけ。強い順に フリーズ（3連単が当たって、その3頭に超大穴＝10〜12番人気がいる。13番人気より下は入れない）＞ デカ（3連単が当たり）＞ 的中（それ以外の当たり）
  • 人気は、そのレースを判定したときの単勝オッズの順（判定の超大穴 J・K・L と同じ）。人気がわからないレースはフリーズにしない（デカ）※仮
  • お知らせ（発走15分後）から開いて記録したときも同じ

流れと時間（的中・デカ）

  • 的中：押す → 0.3秒 馬が下から → 0.95秒「的中！」→ 1.15秒〜 買い目 → 1.8秒 とじる
  • デカ：押す → 0.2秒 白く光る → 0.25秒 虹の光の筋と輪 → 0.85秒 光の中から馬 → 1.5秒「デカ的中!!」→ 1.75秒〜 買い目 → 2.5秒 とじる
  • PUSHは横長の長方形（角は丸い）。上下に0.9秒（デカは0.8秒・大きく・まわりに虹の輪）でくり返す

フリーズの流れと時間

  • PUSH：横340×縦170・角46px（デカの1.2倍）。虹色が流れる面・ラメ・白い光がサッと走る・白と紫のふち・まわりに虹の輪。上下に22px・0.85秒／1.3秒ごとにブルブルッ／画面のふちが虹色に光る
  • バグる（0〜1.4秒）：押した瞬間の画面が1コマ（1/30秒）ずつバグる：横にズレる・赤と水色に色ずれ・緑で色が反転・暗く・水色に白く・紫・ブロック・横の線・縦の線・走査線・砂嵐 → 0.5秒 一瞬もとに戻る → 0.86秒 テンゲルのアイコンのドアップ（バグりながら少し引く）→ 1.2秒 横に流れる光の筋
  • プチュン（1.4秒〜）：画面が青く光って、まん中の白い光が2回ふくらむ・稲妻がジリジリ → 1.64秒 画面が縦につぶれて青白い横一本線（まん中に光のフレア・線にまとわりつく静電気）→ 1.98秒 線が両はしから点に縮んで消える（光の粒が散る）→ 真っ暗のまま約2秒（フリーズの間）
  • 虹色ネオンの超高速カット（4.4〜9.9秒）：白く光る → テンゲルのアイコン（ネオンの線画・画面よりデカい）が虹色に光りながら左右にブルブル・上下に動く（矢印の帯）→ ネオンのギザギザのトンネル → 一瞬真っ暗 → T・E・N・G・E・R が集まる → 白く光る →「超」「大」「穴」「!!」がドン（星空・集中線・光の玉）→ 赤い画面に「超大穴」の文字の壁（バグる）→ 虹のトンネル → 虹の光がはじける → アイコンのドアップ（ネオン）に「FREEZE」
  • 9.9秒 白い爆発 →「ど的中」が炎と光の中からドーン（光の輪・ゆれ・炎がゆらゆら・光がサッと走る・きらめき。上に小さく SUPER LONGSHOT）→ 11.55秒 上へ → 11.9秒 炎の中から馬がボード → 12.5秒「フリーズ的中!!!」→ 12.75秒〜 買い目 → 13.55秒 とじる

重ねる順（下から）

  • 的中・デカ：暗い幕 → 光 → 馬（うしろの絵）→ ボード（文字はHTML）→ 前足の先（前の絵）（ひづめがボードのふちにかかる）→ 紙ふぶき → とじる → （デカ）白い光
  • フリーズ：黒 → 炎の画面（ゆれる：炎の色・光の筋・炎の粒・コイン・馬とボード・「ど的中」・紙ふぶき）→ ネオンのカット（7つ・白い光）→ プチュン（青い画面・白い光・線・フレア・稲妻・光の粒）→ バグる（押した瞬間の画面の絵・アイコンのドアップ・横に流れる光・かぶせる色・走査線・縦の線・砂嵐・ブロック・横の線）→ 白い爆発・光 → とじる

ボードに書くもの

  • R・当たった買い目（券種・馬番・金額・払戻）・払戻の合計。ユーザーが自分で入れた買い目だけ（判定の画面に点数・組番を出さない決まりはそのまま）
  • デカ・フリーズは3連単の行がいちばん上で虹色の枠（フリーズは光が走る）
  • フリーズ：上に「ど的中」（炎）・見出し「フリーズ的中!!!」・その下に「超大穴 ⑪ 11番人気が3連単に！」の帯・3連単の行の超大穴の馬番に虹色の輪・ボードの枠は虹色（回さない）
  • 払戻が長いと次の行へ。帯のぶんボードが長いので、フリーズは6行まで（7つ以上は上から5行＋「ほか○点」※仮）

テーマ（壁紙）ごとに変えるところ

  • 馬の絵2枚（うしろ・前足の先）と、ボードの四角の位置
  • PUSHの色（--pushA・--pushB・--pushC・--rim・--rimD）・ボードの枠・面・文字（--bFrame・--bFace・--bInk・--hitRed）・光の色（--ray）
  • フリーズは全テーマ共通（変わるのは馬の絵とボードの面・文字だけ）。回る虹（虹のぐるぐる）は使わない（虹色は流れるだけ）
  • シルバー帯・ゴールド帯・マスター帯は指示書9.1の指定どおり（あとで作る）

光と見やすさ

  • 強く光るのは1秒に3回まで（光の点めつで気分が悪くなる人がいるため）。パチスロのように1コマごとに白と黒をチカチカさせない（ネオンは色が流れる・形が動く）。白く光るのは 4.4秒・6.6秒・9.9秒（爆発）・11.45秒の4回、バグるところの水色は0.1秒と1秒の2回だけ。動画の明るさを1コマずつ測って確かめた
  • iPhoneの「視差効果を減らす」がオンなら：バグる・プチュン・ネオンのカット・爆発・ゆれ・炎のゆらゆら・炎の粒・紙ふぶき・PUSHの動きを止める。押すと1秒真っ暗 → 炎の画面と「ど的中」（上）・馬とボードをふわっと出す
  • 音は見本に入れていない

容量

  • 馬の絵は1テーマ約27KB（WebP 2枚）。フリーズで足す絵はテンゲルのアイコン（App Storeのアイコンと同じ絵・WebP 750×750 約52KB）と、アイコンから作ったネオンの線画のマスク2枚（芯 1024 約59KB・光 512 約40KB。neon_icon.py）。ほかの虹・文字・炎・ギザギザ・矢印・爆発・稲妻はCSSとSVG
  • バグるのに使う「押した瞬間の画面の絵」は、アプリでは押した瞬間に撮る（WKWebView の takeSnapshot）。見本では見本の画面の絵（WebP 約60KB）
  • 動きは全部CSS（動画なし）・新しいフォントなし（Dela Gothic One・BIZ UDPゴシック）。いまの馬は見本（牧場の栗毛）
