# kisekae/bcp：結果ボードカスタム（絵の ボード）の 道具

まさちゃんの デザインの 絵（結果ボードの まわりの 絵）を、アプリの 本物の 結果ボードと 合わせる ための 道具。
いまは 見本（iPhone の 画面の 大きさの 写真）を 作る ところまで（第4.119版の あと・2026/11/03〜）。アプリには まだ 入れて いない。

- まさちゃんの 絵は **リポジトリに 入れない**（公開の リポジトリ）。作業フォルダ（例：`/home/claude/work/bcpic/<デザイン>/`）に `src.png`（横 1048px に そろえた 絵）と `cfg.json` を 置く。
- `designs/<name>.json` は デザインごとの 設定の 写し（作業フォルダの `cfg.json` と 同じ）。

## 手順

```
D=/home/claude/work/bcpic/<デザイン>          # src.png と cfg.json が ある フォルダ
python3 kisekae/bcp/bcp_retouch.py $D         # まさちゃんの 指定で 絵の 一部を 消して 描き足す（cfg の retouch が ある とき：orig.png → src.png）
python3 kisekae/bcp/bcp_fg.py     $D          # ボードの 前に ある 馬・前の 紙ふぶきを すき通しの 絵に（cfg の fg が ある とき：fg.png・fgmask.png）
python3 kisekae/bcp/bcp_cutout.py $D          # 見出しの 横の 飾り（星・月桂樹）を すき通しの png に（cfg の cutout が ある とき）
python3 kisekae/bcp/bcp_clean.py  $D          # 絵の ボードの 字・行・飾りを 消す → clean.png（clean_dbg.png：赤＝消した 所・緑＝のこした 所）
python3 kisekae/bcp/bcp_bg.py     $D          # 舞台（390×844pt）の 3倍 1170×2532 の 背景 → <SRV>/bcp_<name>.webp（前の 絵は bcp_<name>_fg.webp）・geom.json（ボードの 面 → 絵の 板 の 射影）
python3 kisekae/bcp/bcp_inj.py    $D          # 見本の 注入 JS → inj.js
python3 kisekae/bcp/bcp_shot.py out.png hit 3 $D/inj.js   # テスト版の ためし（preview）に 注入して 写す（種類・行の 数）
```

`bcp_shot.py` は テスト版（`build_pwa.py`・`TARGET=app TENGEL_TEST=1`）を `<SRV_ROOT>/TEST/` に 作って、`window.__NATIVE` を `true` に して おく。

| `clean.keep_fg` | 前の 絵（fgmask）は 消さない |
| `fg` の `mode: region` の 足し | `polys`・`minus_polys`（形で 足す・ひく）・`only_brown`（四角の 中は 茶色＝馬の 毛 だけ）・`drop_thin_red`（四角の 中の 細い 赤い 線を のぞく・ペン先の 太い 赤は のこす） |
| `fg` の `mode: board_minus` | 布や 馬が ボードの 大部分を かくす 絵：`roi` の 中で、ボードの 面の 紺の かたまり（`min_nav` px 以上・`close_r` で とじて 穴うめ・`vis_seeds` で えらべる）を のぞいた 所 ぜんぶを 前に。`drop_yellow`・`drop_red`（`drop_dark_v` より 暗い 所も）・`drop_white`（青っぽい 白い 字：布の クリーム色は のこす）の 四角で 布に 半分 かくれた チップ・ハンコ・字を のぞく（穴うめの あと） |
| `clean.inpaint` の `not_fg`・`clean.diffuse.gap` | 前の 絵（布・馬）の 所は うめない・うめる 所の まわり gap px は 色の もとに しない（ハンコの にじみ） |
| `clean.keep_soft` | ボードに かかる 光（トロフィーの 光 など）：`box` の 中で あたたかい 色（`rb`）・とても 明るい 所（`v`）ほど もとの 絵を のこす（境目なし）。`exclude` は のこさない 四角（字）・`vmed` は のこす 所の 細い 横線を 縦の メディアンで 消す・`xramp` は 左の はしを なめらかに |
| `clean.side_rays` | 絵の 左右の はしに アプリの 画面が 写って いる とき（まん中の 縦長の 舞台の 外）：舞台の はしの 光の すじを 外へ のばして うめる（花・きらきら・紙ふぶきは のこす）。`x` は 舞台の 左右の はし・`c` は 光の まん中 |
| `clean.resynth` | 光の すじを 作り直す 四角（うすい アプリの 画面が すじに かさなる 所）：下の はしの 行（`edge`）から 光の まん中 `c` へ むかう 線に そって のばした すじで おきかえる。のこす 物（黒板 など）は 四角の 外に・`blend` で なじませる・`paste` で 紙ふぶきを もどす |
| `clean.vfill` | ボードの 中の 横に 長い 飾り（鎖）を 消す 帯：`rect`（まっすぐ）か `line`＋`half`（かたむいた ボード：鎖の まん中の 線と 帯の はばの 半分）。帯の すぐ 上と すぐ 下の 行の 色を 縦に つなぐ（`hmed`：はしの 色の むらを 横に ならす）。`keep` の 形・`keep_fg`・`keep_red` は のこす（紙ふぶきの のこし `keep_conf` は 見ない：鎖の 輪も 紙ふぶきに 見える）。`protect`：帯に かかる 紙ふぶき（`seed`＋`tol` の 色の つながり、または なぞった `poly`＋`color`） |
| `clean.inpaint` の 形ごとの `mode` | なし＝Telea・`rows`（行ごとに 左右を つなぐ：同じ 行の はなれた 形は べつべつ）・`radial`・`diffuse`（まわりの 色を 大きい ぼかし → 小さい ぼかしで かさねる：見出しの 大きな ハンコ・月桂樹）。`clean.diffuse` = `{vmax, within}`（明るい ふち・光は 色の もとに しない・この 形の 中だけ） |
| `clean.resynth` の `edge_line`・`dir` | ななめの はし（黒板の 上の ふち に そって）・`dir: "down"`（はしの 下の 光の すじを 作り直す：うすく 写った「とじる」や タブ） |
| `retouch` | まさちゃんの 指定の 絵の 直し（`bcp_retouch.py`）：`src`（元の 絵 `orig.png`）→ `out`（`src.png`）に `ops` を 順に。`bg_angular`（光の すじの 背景：角度ごとの 色の 中央値＋まわりとの ちがいを なじませる）・`bg_radial`・`diffuse`（まわりの 色で なめらかに）・`clone`（となりの 絵を うつす：毛 など）・`shade`・`stroke`（ふち線を 描く）・`glow`。形は `poly`・`minus`・`clip` |
| `cutout` | 見出しの 横の 飾りを 切り出す 所 |
| `layout` | ボードの 面（350pt 基準）の 中の 場所：見出し（`title_cx`・`title_top`・`title_px`）・小見出し・行（`rows_x`・`rows_top`・`rows_bottom`・`row_h`・`rows_zoom`）・帯（`rib_in`）・飾りの 画像（`star_img`）。`rib`・`many` は 帯が ある とき・行が 4つ 以上の とき の 上書き |
| `close_border`・`close_bg`・`close_shadow`・`close_css` | 絵に「とじる」が 描いて ある とき、本物の「とじる」の ふち・地の 色・光（box-shadow）・ほかの CSS（ふちの 太さ など）を 合わせる |
| `layout.title_style` | 見出しの 色の 形（`silver`：白と 銀＝ハズレの ボード・スタンプ2連勝・`copper`：銅色・`rainbow`：虹色。ない ときは 金） |
| `layout.hide_title` | 見出しを 出さない（絵に 見出しが 大きく 描いて ある とき：ハズレの ボードの 見出しは いつも「ハズレ」） |
| `bpoly`・`brrect`（clean の 形） | ボードの 面（350 × 高さ）の 四角・丸い 四角を 絵の 板（`quad`）へ うつした 形（かたむいた ボード） |

## ボードの 中の きまり（まさちゃんの 指定 2026/11/03）

- 21:49「的中のボードも、全て結果ボードは毎回結果に応じて変わるから、的中⑤スタンプ結果ボード以外は、ボードの中の装飾や文字は残さないでね！」→ ボードの 中の **鎖・旗・星・ハンコ・見出しの 横の 月桂樹・字** は 消す（的中⑤ スタンプだけ そのまま）。
- 21:56「こうゆう、絵をボードで消すのは全部やめてね！調整して！」→ **キャラ・ふきだし・びっくりマーク・ペン など 絵の 部分は 消さない**。ボードに かかる キャラは ボードの 前（`fg`）に 出す（アプリの 字・行の 上）。
- 22:12 まさちゃんの こたえ：ハズレ②の 大きな「ハズレ」の 絵の 字・出世馬2連勝の 金メダル・ボードの 中の 紙ふぶき は のこす。ボードの 外の 帯（「2連続的中！」など）・トロフィー・王冠も のこす。ハズレ⑤と⑥は 名前を 入れかえ（⑤書き換え参戦・⑥作戦会議）。
- 11/04 02:01「ハズレ⑥消して！」・02:02「結果ボードカスタムは、15個にする！ミッションも変更して！」→ ハズレ⑥（作戦会議）は やめた（設定と 見本を 消した）。結果ボードカスタムは 全部で 15こ（的中 9・ハズレ 5・ボードを持つ馬：アプリは 第4.120版）。
