# kisekae/bcp：結果ボードカスタム（絵の ボード）の 道具

まさちゃんの デザインの 絵（結果ボードの まわりの 絵）を、アプリの 本物の 結果ボードと 合わせる ための 道具。
いまは 見本（iPhone の 画面の 大きさの 写真）を 作る ところまで（第4.119版の あと・2026/11/03〜）。アプリには まだ 入れて いない。

- まさちゃんの 絵は **リポジトリに 入れない**（公開の リポジトリ）。作業フォルダ（例：`/home/claude/work/bcpic/<デザイン>/`）に `src.png`（横 1048px に そろえた 絵）と `cfg.json` を 置く。
- `designs/<name>.json` は デザインごとの 設定の 写し（作業フォルダの `cfg.json` と 同じ）。

## 手順

```
D=/home/claude/work/bcpic/<デザイン>          # src.png と cfg.json が ある フォルダ
python3 kisekae/bcp/bcp_fg.py     $D          # ボードの 前に ある 馬・前の 紙ふぶきを すき通しの 絵に（cfg の fg が ある とき：fg.png・fgmask.png）
python3 kisekae/bcp/bcp_cutout.py $D          # 見出しの 横の 飾り（星・月桂樹）を すき通しの png に（cfg の cutout が ある とき）
python3 kisekae/bcp/bcp_clean.py  $D          # 絵の ボードの 字・行・飾りを 消す → clean.png（clean_dbg.png：赤＝消した 所・緑＝のこした 所）
python3 kisekae/bcp/bcp_bg.py     $D          # 舞台（390×844pt）の 3倍 1170×2532 の 背景 → <SRV>/bcp_<name>.webp（前の 絵は bcp_<name>_fg.webp）・geom.json（ボードの 面 → 絵の 板 の 射影）
python3 kisekae/bcp/bcp_inj.py    $D          # 見本の 注入 JS → inj.js
python3 kisekae/bcp/bcp_shot.py out.png hit 3 $D/inj.js   # テスト版の ためし（preview）に 注入して 写す（種類・行の 数）
```

`bcp_shot.py` は テスト版（`build_pwa.py`・`TARGET=app TENGEL_TEST=1`）を `<SRV_ROOT>/TEST/` に 作って、`window.__NATIVE` を `true` に して おく。

## cfg.json

| キー | 中身 |
|---|---|
| `name` | 名前（背景の ファイル `bcp_<name>.webp`） |
| `quad` | 絵の 板の 四すみ（左上・右上・右下・左下・px）。ボードの 面（350pt × 高さ）を ここへ 射影 |
| `S`・`cx`・`top_pt` | 絵の 大きさ（pt/px）・舞台の まん中に 来る 絵の x・板の 上の はしの 高さ（pt） |
| `crop` | 絵の 上と 下の 使わない 行（うすく 写りこんだ アプリの 画面 など） |
| `fill` | 絵の 上と 下の すき間の うめ方：`mirror`（床に うつる）・`radial`（光の すじを のばす：`c` が 光の まん中）・`glow`（光を ぼかして 暗く）。`top`・`bottom` で 上と 下を べつに |
| `clean.regions` | 消す 所（`navy`：その 点の 紺の かたまり・`rect`・`rrect`・`poly`）。`only: "text"` は 字（金・白・光）だけ 消して 地の もようを のこす。`bg` は その 所の 地の 色の きまり |（`bg.poly`：まわり `grow` px の 地の 点に 2次の 面を あてはめて うめる＝見出しの 所の なめらかな 光の むら・`bg.gmax`：緑の 強さの 上限で 行の 帯と すき間を 分ける）
| `clean.keep`・`keep_red`・`crowd`・`keep_conf` | のこす もの（ハンコ・下の 馬たち・ボードの 外まで はみ出す 紙ふぶき） |
| `clean.force`・`patch`・`inpaint`・`deghost` | かならず 消す 所・となりの 絵を ずらして はる（旗の 下の 鎖）・絵に 描いて ある ボタンを うめる・うすく 写りこんだ アプリの 画面を 消す |（`deghost.dark_max`：光の すじの あいだの 暗い 所だけ なめらかに・`inpaint_mode: radial`：光の すじの むきに そって うめる）（`patch` の `dx: "auto"`：つなぎ目の 左右が いちばん 合う ずらしを さがす）
| `fg` | ボードの 前に ある もの：`seeds`（馬の 中の 点・ボードの 中）から 紺で ない 所を つないで、`grabcut` で 絵の ふち線で 切り直す（`quad_margin`：ボードの まわり だけ）。`conf` は 前の 紙ふぶき（色の まぜ具合で すき通し）。アプリの ボードは 背景と この 絵の あいだ |
| `clean.keep_fg` | 前の 絵（fgmask）は 消さない |
| `clean.keep_soft` | ボードに かかる 光（トロフィーの 光 など）：`box` の 中で あたたかい 色（`rb`）・とても 明るい 所（`v`）ほど もとの 絵を のこす（境目なし）。`exclude` は のこさない 四角（字）・`vmed` は のこす 所の 細い 横線を 縦の メディアンで 消す・`xramp` は 左の はしを なめらかに |
| `clean.side_rays` | 絵の 左右の はしに アプリの 画面が 写って いる とき（まん中の 縦長の 舞台の 外）：舞台の はしの 光の すじを 外へ のばして うめる（花・きらきら・紙ふぶきは のこす）。`x` は 舞台の 左右の はし・`c` は 光の まん中 |
| `cutout` | 見出しの 横の 飾りを 切り出す 所 |
| `layout` | ボードの 面（350pt 基準）の 中の 場所：見出し（`title_cx`・`title_top`・`title_px`）・小見出し・行（`rows_x`・`rows_top`・`rows_bottom`・`row_h`・`rows_zoom`）・帯（`rib_in`）・飾りの 画像（`star_img`）。`rib`・`many` は 帯が ある とき・行が 4つ 以上の とき の 上書き |
| `close_border`・`close_bg`・`close_shadow`・`close_css` | 絵に「とじる」が 描いて ある とき、本物の「とじる」の ふち・地の 色・光（box-shadow）・ほかの CSS（ふちの 太さ など）を 合わせる |
| `layout.title_style` | 見出しの 色の 形（`silver`：白と 銀＝ハズレの ボード。ない ときは 金） |
| `layout.hide_title` | 見出しを 出さない（絵に 見出しが 大きく 描いて ある とき：ハズレの ボードの 見出しは いつも「ハズレ」） |
| `bpoly`・`brrect`（clean の 形） | ボードの 面（350 × 高さ）の 四角・丸い 四角を 絵の 板（`quad`）へ うつした 形（かたむいた ボード） |
