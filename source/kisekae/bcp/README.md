# kisekae/bcp：結果ボードカスタム（絵の ボード）の 道具

まさちゃんの デザインの 絵（結果ボードの まわりの 絵）を、アプリの 本物の 結果ボードと 合わせる ための 道具。
見本（iPhone の 画面の 大きさの 写真）を 作って（第4.119版の あと・2026/11/03〜）、**第4.121版（2026/11/04）で アプリに 入れた**（下の「アプリに 入れる」）。

- まさちゃんの 絵は **リポジトリに 入れない**（公開の リポジトリ）。作業フォルダ（例：`/home/claude/work/bcpic/<デザイン>/`）に `src.png`（横 1048px に そろえた 絵）と `cfg.json` を 置く。
- `designs/<name>.json` は デザインごとの 設定の 写し（作業フォルダの `cfg.json` と 同じ）。

## 手順

```
D=/home/claude/work/bcpic/<デザイン>          # src.png と cfg.json が ある フォルダ
python3 kisekae/bcp/bcp_retouch.py $D         # まさちゃんの 指定で 絵の 一部を 消して 描き足す（cfg の retouch が ある とき：orig.png → src.png）
python3 kisekae/bcp/bcp_fg.py     $D          # ボードの 前に ある 馬・前の 紙ふぶきを すき通しの 絵に（cfg の fg が ある とき：fg.png・fgmask.png）
python3 kisekae/bcp/bcp_cutout.py $D          # 見出しの 横の 飾り（星・月桂樹）を すき通しの png に（cfg の cutout が ある とき）
python3 kisekae/bcp/bcp_clean.py  $D          # 絵の ボードの 字・行・飾りを 消す → clean.png（clean_dbg.png：赤＝消した 所・緑＝のこした 所）
python3 kisekae/bcp/bcp_bg.py     $D          # 舞台（390×844pt）の 3倍 1170×2532 の 背景 → <SRV>/bcp_<name>.webp（前の 絵は bcp_<name>_fg.webp）・geom.json（ボードの 面 → 絵の 板 の 射影）
python3 kisekae/bcp/bcp_inj.py    $D          # 見本の 注入 JS → inj.js
python3 kisekae/bcp/bcp_shot.py out.png hit 3 $D/inj.js   # テスト版の ためし（preview）に 注入して 写す（種類・行の 数）
```

`bcp_shot.py` は テスト版（`build_pwa.py`・`TARGET=app TENGEL_TEST=1`）を `<SRV_ROOT>/TEST/` に 作って、`window.__NATIVE` を `true` に して おく。

## アプリに 入れる（第4.121版）

- **番号と 段**：`bcp_app.py` の `ITEMS`（`points.js` の `BOARD_ITEMS` の 1〜14 と 同じ id・when）。段＝[連続の 数, デザイン]：その 数から その 絵（いちばん 上の 段は その 上も）。
  的中①〜⑧（ring・toast・race・snap・seal・cup・hoist・bloom）＝1・2・3・4連勝〜／的中⑨ 出世馬（climb）＝1・2・3・4・8・16・24連勝〜／
  ハズレ①〜⑤（rain・next・cover・wait・pen）＝続けて ハズレた 数 1・2・3・4回目〜（`points_ui.js` の `board.mstreak`：ハズレで +1・的中で 0）。
- **置き方の データ**：`build_pwa.py`（`TARGET=app`）が `bcp_app.bundle_js()`（`window.__BCP`：デザインごとの 板の 四すみ `q`（舞台の pt）・ボードの 高さ `hp`・前の 絵 `fg`・見出しの 色 `ts`・見出しなし `nt`・字と 行の 場所 `L`・「とじる」の 色 `cl`）を index.html に 入れる。
  `designs/<name>.json` から 作る（`bcp_bg.py` と 同じ 計算。`python3 kisekae/bcp/bcp_app.py` で 作業フォルダの `geom.json` と 同じかを 確かめる）。
- **絵**：`bcp_<デザイン>.webp`（背景 1170×2532）・`bcp_<デザイン>_fg.webp`（ボードの 前）・`bcp_t_<id>.webp`（設定の タイルの 見本 360×480）＝ぜんぶで 108こ（約 17MB）。
  **リポジトリに 入れない**（まさちゃんの 絵）。手元の `ios/bcp_assets/`（`.gitignore`）か `BCP_ASSETS=<フォルダ>` から `build_ios.py` が Resources に 入れる。ない とき（CI）は いつもの ボードで 出る。
  - 背景・前の 絵：`bcp_bg.py` が `<SRV>/bcp_<name>.webp` に 書いた もの を `ios/bcp_assets/` へ コピー（`python3 kisekae/bcp/bcp_app.py ios/bcp_assets` で そろって いるか 確かめる）。
  - タイルの 見本：`python3 kisekae/bcp/bcp_thumbs.py <アプリの 画面の フォルダ> ios/bcp_assets [シート.png]`（いちばん はじめの 段の 結果の 画面を 2倍で 写して たて 3:4 を 切り出す。
    アプリの 画面の フォルダは `TARGET=app python3 build_pwa.py <フォルダ>`・`window.__NATIVE = true;` に かえて 絵を 置いた もの）。
- **動かす 所**：`bcx.js` の「絵の ボード」。`.hb`（ボードの 入れもの）の 中に 舞台 ぜんぶの 入れもの `.bcpw`（絵 → ボード `.rb` → 前の 絵）。`.rb` は 板の 四すみへ `matrix3d`（4点の 射影を その場で 解く）。
  字と 行は 見本（`bcp_inj.py`）と 同じ 置き方・同じ 色（テーマの 色・ふち・飾り・字は 消す）。その 演出の ボードが 出る 時（`.hb` の 登場：時刻は そのまま・動きは 消す）に 絵ごと ふわっと（デカ的中から 上は 少し 明るく）→
  出おわったら ほかの 絵（光・紙ふぶき・動画の コマ）を かくす。設定の「▶ 見る」は 押す たびに つぎの 段。絵が 読めない → いつもの ボード。
- **テスト**：`test_points.js`（番号・id・when）・`test_native.py`（設定の タイル・「▶ 見る」の 段・解放の 順・連続の 数・段の 決め方・読めない とき：ハズレ⑤の 絵だけ わざと 置かない）・
  `test_iphone_only.py`（データと 絵の 数）・`test_bcx_flash.py pic`（点めつ）・CI の `selftest.js`（絵なしで いつもの ボードに もどる）。

## 動き（実験・`motion/`・まだ アプリには 入れて いない）

まさちゃん（2026/11/04 21:47）「今は静止画だと思うけど、少し動きのエフェクトをつけることは可能？ 例えばちょとプルンと動きとか、立体感を出して少し動かすか！ まだこれは、実験ね！」

- `motion/bcp_motion_exp.js`：アプリの ためしに あとから 足す 注入（`bcx.js` は かえて いない）。`.bcpw` の 中を `.bcpm`（ぷるん）> `.bcpt`（立体）> [絵・ボード `.rb`・前の 絵] に して、**絵ごと 動かす**
  （うしろの 絵・アプリの ボード・前の 絵が いっしょに 動く ので、絵が ずれたり 二重に なったり しない＝新しい 絵は いらない・15こ ぜんぶ 同じ しくみ）。
  - ぷるん：ボードが 出はじめて 0.3秒 から 0.9秒（よこ 1.045 → たて 1.04 → … の ばね）。さわると もう一度（`window.__bcpPoke()`）。大きさは 1 より 小さく しない（画面の はしが 見えない）。
  - 立体：7秒で 1回り（たて 1.1度・よこ 2.2度・遠近 1000px）。はしの すき間が 出ない いちばん 小さい 大きさを その場で 計算（`cover`）。ボードの ガラスに 光の 帯が かたむきに 合わせて すべる（`.bcpgl`）・アプリの 字が 少し 浮く（1.6px まで）。
  - 「的中エフェクト」が 控えめ／オフ（`.bcst`）・「視差効果を減らす」（`prefers-reduced-motion`）では 動かさない。点めつ（`kisekae/flash_px.py`）は 5つの 見本で 窓 0個。
- 見本の 動画：`python3 kisekae/bcp/motion/shots.py <コマの フォルダ> kisekae/bcp/motion/clips.json`（1/60秒ずつ 写す・`DPR=2`）→ `python3 kisekae/bcp/motion/make_video.py <コマの フォルダ> <出す mp4> A_purun,B_tilt,C_both,D_race4,E_cover`。
- キャラだけ 動かす（馬が はねる・ハンコを ポンと おす など）は、絵ごとに キャラを 切りぬいて うしろを 描きたす 作業が いる（今の 絵は キャラと うしろが 1まい）。

### キャラだけ 動かす（実験・`chr/`・まさちゃん 2026/11/04 22:15「やるならキャラクターだけ！」）

- **ためした 絵**：的中⑤ スタンプ（1連勝・`stamp1`）。馬（ぷるん と 息を する 2.6秒・ゆっくり 3Dで 首を ふる 7秒）と ハンコ（3.2秒に 1回「ポン」と おして ぷるん と もどる・ゆっくり 3Dで かたむく 8秒）。ボード・光・紙ふぶきは 動かない。
  22:53 まさちゃん「もう少し動き弱くしてみて！」→ 大きさを 半分くらいに（息 1.2%・首ふり 4度・ポン 6%・かたむき 3.5度。時間は そのまま）。
  23:01 まさちゃん「腕とキャラクター一緒に動かしてみて！」→ ハンコを にぎる 馬の 腕が 馬と ハンコに 分かれて いて、ハンコの 左の ひづめは 背景の まま だった。馬・腕・ひづめ・ハンコを 1つの 絵に（`chr/stamp1_group.json`・`kind: group`・`chr/chr_stage_group.json`）して、いっしょに「ポン」と おして ぷるん（3.2秒に 1回・つぶれ 3.8%）・3Dで 向きを かえる（4度・7秒）。
- **切りぬき**：`chr/seg.py`（アニメの 絵の 切りぬき isnet-anime を onnxruntime で：`python3 chr/seg.py <絵> <x0,y0,x1,y1> <mask.png>`・
  モデル `isnet-anime.onnx`（176MB・リポジトリに 入れない）は `/home/claude/work/models/`。rembg の GitHub の リリースから 落とす）→ `chr/chr_split.py <設定>`（例 `chr/stamp1.json`）。
  - キャラごとの 印（`inner`・`outer`・`from_mask`）から watershed（キャラ どうしの さかいは 絵の ふち線）。ボードの うしろに かくれる 所は `clip`（ボードの 上の ふち）で 切る（ボードの 前の ひづめは `keep`）。
  - キャラの まわりの 光の ふち・ふち線は「キャラを 消して 光の すじで うめた 色」と 元の 絵が ちがう 所（`glow_px` 12・`glow_thr` 22）を キャラに 入れる → **止まって いる ときは 元の 絵と 同じ**（ちがい 0）。
