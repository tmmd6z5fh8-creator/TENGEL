## ① 顔（face_fix.py）

- まだら＝ほおの「明るい 面と 暗い 面が ぎざぎざに 分かれた もよう」と 細い 暗い すじ・点（3D の かげの 計算の あと）。顔を 上げる 間（コマ 30〜112）ずっと 写って いる。
- ほおの 形（左の ほお L1・左の あご L2・右の ほお R1）は コマ 90 で 決めて、**ほお 1つずつ** 顔の 動きを 追って うつす（`face_track.py`：ほおの 中の もようを となりの コマへ 追って 平面の 変形〈ホモグラフィ〉を つなぐ → コマ 90 と じかに 合わせ直す）。
  顔を 上げる 動きは 立体の 回り なので、顔 ぜんぶを 1つの 変形で 追うと はじめの コマで 40〜80px ずれる。
- はじめ（〜コマ 62：ほおが 細い 光の 帯）：帯の ふち（左右）を 行ごとに 見つけて まっすぐに のばし、帯の 長い 向きに そって 見た「明るい 面の 明るさ」で **暗い まだら だけ** うめる
  （ふちの 光の 線・帯の ふちは 長い 向きに そって いる ので ぼやけない・明るい 所は さわらない）。
- あと（コマ 78〜：ほおが 広い 面）と 左の あご：まるく 広く ならした 明るさ（平均）と ちがう 所 だけ 入れかえる（まだらで ない 所の かげは そのまま）。62〜78 は 2つを 少しずつ まぜる。
- 暗い はじめの コマは、ほおの 明るさを コマ 90 と そろえて から 直して もどす。雷・金の つや（明るくて 細い もの）・まっ白に とんだ 所は さわらない。
- コマ 113（ばくはつの かけらが 顔の 前を とぶ・目の 光で ほおも 白く とぶ）は さわらない。
- ためした けれど やめた 形：顔 ぜんぶを 1つの 変形で 追う（ずれる）／暗い 方へ そろえる（はじめの コマで ほおが くすむ）／まるく ならす だけ（帯の ふちが ぼやける）／雷の あわい 所まで まもる（まだらの 明るい かけらが 白い すじに のこる）。

## ② かけら（debris.py）

- かけらは ばくはつの まん中から 外へ（＝画面の 手前へ）とぶ：あとの コマ ほど・まん中から はなれた かけら ほど 画面に 近い。
- かけらの ない 白い 光の 面を 作って（大きな closing → ならす）、かけらの 暗さを k 倍に：コマ 116 で 0.95 → 120 で 0.57 → 124 で 0.31 → 130 で 0.11（`KT`）、画面の はし（まん中から 750px より 外）は さらに 0.6倍。
- 大きな かけら（ぼやけた 暗い かたまり ＝ 近い）と 小さな もの（小石・細い すじ ＝ 遠い）を 分けて、小さな ものは ゆるく（倍率の 0.5乗）。ばくはつの 放射の あわい かげ（深さ 12 まで）は そのまま。

## ③ 寄り（slowcu.py）

- となりの コマの 動き（DIS の 動きの 場：寄りの 中は 1コマに 約 8px 上へ 流れる）を 追って、前の コマと 後の コマを その 時刻の 所へ よせて 重ねる。行きと 帰りの 動きが 合わない 所（かくれる 所・速い 小さな つぶ）は 近い 方の コマを 多く 使う（二重に 写さない）。
- 寄り 1つの はじめと おわりは もとの コマ（24コマ＝もとの 10コマぶんを ひとしく：1コマに 約 3.4px）。
